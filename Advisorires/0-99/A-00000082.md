# Silicon Labs Security Advisory A-00000082 : Secure Link vulnerability in WFx devices running firmware versions 3.4.0, 3.4.1, and 3.5.0.

Flags: Wi-Fi

CVSS Severity: Low

CVSS Base Score: 3.7 Low

CVSS Temporal Score: 3.5 Low

CVSS String: CVSS:3.1/AV:P/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N/E:F/RL:O/RC

## Description

- An attacker with physical access to the communication bus (SPI or SDIO) can send unencrypted commands to the device, even if the Secure Link encryption is enabled. These commands can disable Secure Link encryption, which can reveal information about the connected network and allows the attacker to falsify information about the network to the host.

- If an application is using application level security (TLS), sensitive application data is not visible to the WFx device, therefore customer sensitive data cannot be leaked with this method.

### Fix/Workaround

- This vulnerability has been patched in the WFx firmware version 3.6.0 (released 5 May 2020). Customers using Secure Link are advised to upgrade to firmware version 3.6.0 or later.

- Hosts should also upgrade their driver versions to support this fix.
    - Hosts running the WFx Linux driver should update to version 2.6.1 (released 2 September 2020) or later.
    - Hosts running the WFx Full-MAC (FMAC) driver should update to version 3.0.4 (released 20 July 2020) or later.
