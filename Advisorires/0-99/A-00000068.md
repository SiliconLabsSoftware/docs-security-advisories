# Silicon Labs Security Advisory A-00000068 : Zigator-related DoS and Eavesdropping attacks on Zigbee Gateways and End Devices

Flags: Zigbee

CVSS Severity: Medium

CVSS String: CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H/E:F/RL:O/RC:C 

## Product Impact

EM35x and EFR32 SoC’s and modules running EmberZNet

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| ------- | ---------------- | -------- | ---------------- | --- |
| EmberZNet | 6.5.0 and earlier | GSDK | 2.5.0 and earlier | - |

## Description

- Security researchers Dimitrios-Georgios Akestoridis, Madhumitha Harishankar, Michael Weber, and Patrick Tague of Carnegie Mellon University have published a paper entitled, “Zigator: Analyzing the Security of Zigbee-Enabled Smart Homes” at the ACM WiSec 2020 conference. URL is here: 
http://mews.sv.cmu.edu/papers/wisec-20.pdf 
- The paper details several known weaknesses in Zigbee including denial of service attacks and eavesdropping attacks that they exploited using a sniffing and selective jamming tool they developed called Zigator. URL describing Zigator tool and additional resources is here: 
http://mews.sv.cmu.edu/research/zigator/ 
- The attacks presented by the researchers represent well-known weaknesses in the protocol standard that most product vendors and ecosystems have already addressed in their products. 
- Regardless, Silicon Labs recommends that all vendors audit their products and ecosystems in order to ensure that these known issues have been properly addressed. 

### Fix/Workaround

| Attack Type | Silicon Labs Recommendations |
| --- | --- |
| DoS: Various PAN ID attacks (Gateway-only) | EmberZNet PRO versions prior to 6.5.1: The Network Manager/Trust Center will automatically make a change to the PAN ID if it receives several PAN ID conflicts within a short time period. The threshold is controlled by EMBER_PAN_ID_CONTLICT_REPORT_THRESHOLD. Increasing the threshold will Various PAN reduce the rate and impact of PAN ID spamming. EmberZNet PRO versions 6.5.1 and later: The Network Manager/Trust Center does not directly make changes to the PAN ID based on conflict reports. Instead, conflicts are reported to an application handler emberPanIdConflictHandler() and the application can rate-limit PAN ID updates.
| DoS: Spoofed MAC acknowledgements | 1. Enable encrypted "End Device Timeout Requests.” 2. Implement logic on the hub to monitor end-to-end network connectivity, specifically looking for aberrations in expected regular traffic.
| Eavesdropping: Default TCLK issues | 1. Use device-unique install codes, per Zigbee 3.0 specification. 2. Negotiate a new Trust Center Link Key instead of relying on the ZA09 default TCLK.
| Eavesdropping: Network packet sniffing | 1. Hackers can infer network topology and the roles of individual nodes via sniffing and network analysis. Action recommended: none. 2. Hackers can identify devices on the network by using the IEEE address. Action recommended: none.
| Evesdropping: QR Codes | End-product documentation should advise users of the security risks associated with QR codes falling into the wrong hands.
