# Silicon Labs Security Advisory A-00000110 : Bluetooth Classic Vulnerability in BT121-A ASB-U Injection Attack Using Active Slave Broadcast

Flags: Bluetooth

CVSS Severity: High

CVSS Base Score: 8.8

CVSS Temporal Score: 7.9

CVSS String: CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H/E:P/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| BT121-A SDK | 1.5.0 and earlier | - | - | - |

### Source Product Impact Details

- BT121-A SDK 1.5.0 and earlier

- RS9113/RS9116 SoCs and modules do not support connectionless slave broadcast (CSB) so they are not impacted

- WT11U, WT12A, WT32I and WT41U modules are not impacted

- EFR32 SoCs and modules are not impacted since they do not support Bluetooth Classic

## Description

- An unauthorized third party can inject data into a trusted connection through a connectionless slave broadcast, bypassing encryption

- The Bluetooth member statement is available [here](http://go.bluetooth.com/e40PsF03000RBA0E2e3tL0Q). Membership with the Bluetooth SIG and login required

### Fix/Workaround

- For BT121-A upgrade to [SDK 1.6.0 or later](https://www.silabs.com/wireless/bluetooth/bluegiga-classic-legacy-modules/device.bt121-a#software)

- No other Silicon Labs products are impacted
