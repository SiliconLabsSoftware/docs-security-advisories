# Silicon Labs Security Advisory A-00000111 : Bluetooth LE Remote Code Execution and Denial of Service

Flags: Bluetooth

CVSS Severity: High

CVSS Base Score: varies

CVSS Temporal Score: varies

CVSS String: varies

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| BGX13 SDK | 1.2.2 and earlier | GSDK | 2.7.0 and earlier | [CVE-2020-15531](https://nvd.nist.gov/vuln/detail/CVE-2020-15531), [CVE-2020-15532](https://nvd.nist.gov/vuln/detail/CVE-2020-15532) |
| Bluetooth LE SDK | 2.13.2 and earlier | GSDK | 2.7.0 and earlier | [CVE-2020-15531](https://nvd.nist.gov/vuln/detail/CVE-2020-15531), [CVE-2020-15532](https://nvd.nist.gov/vuln/detail/CVE-2020-15532) |

### Source Product Impact Details

(update from previous security advisories SA-200720003 and SA-200720004)

This advisory as a follow-on to security advisories SA-200720003 and SA-200720004 published in August 2020, which are appended to this advisory for reference. This advisory contains updates to the impacted products.

## Product Impact

- BGX13 modules running SDK version 1.2.2 or earlier

- EFR32 SoC’s and associated modules running Bluetooth SDK version 2.13.2 or earlier supporting Central or Observer roles and supporting extended advertising (does not include EFR32xG1B/EFR32xG1P/EFR32xG1V SoCs or associated modules).

### Fix/Workaround

- This vulnerability has been patched (Bug ID #466477) in Bluetooth SDK version 2.13.3 included in GSDK version 2.7.3 or later and GSDK version 3.x x.
- Instructions for updating to recommended fixed versions are found in the table below

| Product | Instructions |
| --- | --- |
| EFR32 SoCs and modules other than BG13X | These vulnerabilities have been patched (Bug ID #466477) in Bluetooth SDK version 2.13.3 included in GSDK version 2.7.3 or later and GSDK version 3.x. Devices running older versions of the Bluetooth stack should be updated. Upgrade instructions can be found in [AN1086: Using the Gecko Bootloader with the Silicon Labs Bluetooth® Applications](https://www.silabs.com/documents/public/application-notes/an1086-gecko-bootloader-bluetooth.pdf). |
| BG13X | Update to BGX13 Software version 1.3.x or later, instructions can be found [here](https://docs.silabs.com/gecko-os/1/bgx/latest/firmware-update)
