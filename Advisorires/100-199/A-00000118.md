# Silicon Labs Security Advisory A-00000118 : Onebox Utility Command Injection Vulnerability

Flags: Security

CVSS Severity: High

CVSS Base Score: 8.8

CVSS Temporal Score: 8.4

CVSS String: AV:L/AC:L/PR:L/UI:N/S:C/C:H/I:H/A:H/E:H/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| RS9113 and RS9116 based nLink modules | 2.0 and earlier | - | - | [CVE-2020-25851](https://nvd.nist.gov/vuln/detail/CVE-2020-25851) |

### Source Product Impact Details

- RS9113 and RS9116 based nLink modules.

## Description

- An attacker may run the onebox_util tool with a malicious interface name potentially resulting in escalating to root privilege.

- This issue is listed as [CVE-2020-25851](https://nvd.nist.gov/vuln/detail/CVE-2020-25851)

### Fix/Workaround

- Upgrade to OneboxUtil 2.1
