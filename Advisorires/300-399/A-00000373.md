# Silicon Labs Security Advisory A-00000373 : IV generation vulnerability in wolfSSL 5.0.0/5.1.0 does not impact Silicon Labs products

Flags: Security

CVSS Severity: Medium

CVSS Base Score: 7.5, High

CVSS Temporal Score: 6.5, Medium

CVSS String: CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N/E:U/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| wolfSSL | 5.0.0 or 5.1.0 | - | - | [CVE-2022-23408](https://nvd.nist.gov/vuln/detail/CVE-2022-23408) |

### Source Product Impact Details

- Devices running wolfSSL version 5.0.0 or 5.1.0 utilizing AES-CBC or DES3-CBC cipher suites in TLS 1.1 or TLS 1.2 connections may be impacted.

- EFR32 devices do not run wolfSSL, so they are not impacted.

- RS911x devices run wolfSSL 3.9.10, so they are not impacted.

## Description

- wolfSSL internally discovered a vulnerability in the wolfSSL TLS block cipher suite. The IV generated for connections using AES-CBC or DES3 with TLS/DTLS 1.2 or 1.1 is not random.

- [CVE-2022-23408](https://nvd.nist.gov/vuln/detail/CVE-2022-23408) has been reserved for this issue.

- Additional information about this vulnerability can be found at [wolfSSL’s vulnerabilities page](https://www.wolfssl.com/docs/security-vulnerabilities/).

### Fix/Workaround

- Impacted devices should upgrade to wolfSSL version 5.1.1 or higher.
