# Silicon Labs Security Advisory A-00000387 : Periodic Z-Wave S0 security NonceGetrequests can result in Denial-of-Service

Flags: Z-Wave

CVSS Severity: Medium

CVSS Base Score: 5.3, Medium

CVSS Temporal Score: 4.8, Medium

CVSS String: CVSS:3.1/AV:A/AC:H/PR:N/UI:N/S:U/C:N/I:N/A:H/E:P/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Z/IP Gateway SDK | 7.17.1 and earlier | - | - | [CVE-2022-24611](https://nvd.nist.gov/vuln/detail/CVE-2022-24611) |

### Source Product Impact Details

- Z-Wave devices running the Z-Wave Z/IP Gateway SDK 7.17.1 or earlier and configured to allow S0 security commands are impacted

- Z-Wave devices configured to allow S0 security commands may be impacted

## Description

- When a device responds to the Z-Wave S0 NonceGetrequest command, it is required to wait for at least 3 seconds for the reply to the nonce. An attacker with a valid NodeID can send a minimal number of nonce requests (1 every 2 seconds) to keep the target device busy waiting on receipt notifications, resulting in a denial-of-service.

- This attack requires one or more valid NodeIDs that can be spoofed to send valid NonceGetrequest commands. More information on the vulnerability and how to find exploitable NodeIDs can be found [in this research](https://urldefense.com/v3/__https:/itsec-lab.hs-emden-leer.de/sec-insights/2022/04/28/amazon-ring-zwave-dos-attack.html__;!!N30Cs7Jr!S4Q4Gtc9L-j1WD1GgJ5IllVss_NUJgw_fD2bORTpFxyTn53toMkpbPYTHPLG_pG68KV1jcrNO2dhpFeJSaS2BggN2xSxB2rbuxHl7Ayt$).

- [CVE-2022-24611](https://nvd.nist.gov/vuln/detail/CVE-2022-24611) has been assigned to this issue.

- This vulnerability is related to those disclosed in October 2019 in Silicon Labs Security Advisory A- 00000006.

### Fix/Workaround

- All systems that are sensitive to localized denial-of-service attacks (e.g., jamming or battery drain) should implement a heartbeat or other network health checks to detect these types of conditions and respond accordingly based on the application use case to promote a safe and secure system state. Examples of such health checks are given in Reference [1] below.

- We recommend disabling S0 support where possible. This protects against other known S0 vulnerabilities as well, such as those described in March 2022 in Silicon Labs Security Advisory A-00000375.

- A mitigation will be available in Z-Wave Z-IP Gateway SDK 7.18.0, targeted for release June 2022. This mitigation decreases the effectiveness of the attack but does not prevent it entirely. See the first bullet above for recommendations how to detect and respond to denial-of-service attacks. Impacted devices should upgrade to Gateway SDK 7.18.0 or newer as follows: 
    1. In Simplicity Studio’s Help menu, select the ‘Update Software’ menu item to open the Installation Manager
    2. Click the ‘Manage installed packages’ button
    3. Select the ‘SDKs’ tab and expand the ‘Z-Ware and Z/IP Gateway’ section
    4. Find the desired ‘Z-Wave Z-IP Gateway SDK’ version and click ‘Install’
