# Silicon Labs Security Advisory A-00000332 : Bluetooth LE multiple advertisements use same private address, which weakens LE Privacy

Flags: Bluetooth

CVSS Severity: Medium

CVSS Base Score: 4.3

CVSS Temporal Score: 4.1

CVSS String: CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:L/I:N/A:N/E:H/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Bluetooth LE SDK | 3.2.1 and earlier | GSDK | 3.2.1 and earlier | - |

### Source Product Impact Details

- EFR32-based SoCs and modules using Gecko SDK 3.2.1 or earlier are impacted.

- BT121, BT122, BLE1xx, WTxx modules and RS9113/RS9116W-based modules and SoCs are not impacted since they do not support the impacted features.

## Description

- Devices employing multiple advertisement sets with LE privacy should use a different address for each advertising set. The impacted SDKs use the same resolvable private address for all advertisement sets after the first resolvable private address generation interval, leading to a breach of confidentiality.

### Fix/Workaround

- EFR32 customers should update to Gecko SDK 3.2.2 as follows: 
    1. In the Simplicity Studio help menu, select the update software menu item.
    2. Click the manage installed packages button.
    3. On the SDKs tab, set the category filter to ‘Bluetooth’ and the ‘version’ filter to ‘latest’.
    4. Click the update button.
