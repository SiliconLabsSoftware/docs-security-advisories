### Source Product Impact Details

- EFx32 SoCs and associated modules running the TCP/IP stack of MicriumOS of GSDK version 3.2.2 and earlier.

## Description

- Forescout Research Labs published a report, [NAME:WRECK](https://www.forescout.com/research-labs/namewreck/), which includes 8 vulnerabilities in common TCP/IP stacks. The susceptibility of GSDK version 3.2.2 and earlier to each of these vulnerabilities is listed in the first table below.

### Fix/Workaround

- Upgrade the GSDK to version 3.2.3 or later to obtain the patched version of MicriumOS. 
    1. In Simplicity Studio’s help menu, select the ‘Update Software’ menu item to open the Installation Manager.
    2. If working with Simplicity Studio v5, click ‘Manage installed packages’ to view the Product Updates. 
    3. Apply any required updates. 
    4. Select the ‘SDKs’ tab and choose the relevant stack(s) for your application then click the ‘Install’ button.
