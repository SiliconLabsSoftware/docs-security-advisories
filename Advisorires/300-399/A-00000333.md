# Silicon Labs Security Advisory A-00000333 : “BadAlloc” Vulnerability in Amazon FreeRTOS

Flags: Security

CVSS Severity: Medium

CVSS Base Score: 7.3, High

CVSS Temporal Score: 6.4, Medium

CVSS String: CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:L/A:L/E:U/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| FreeRTOS | 10.4.1 and earlier | GSDK | 3.0 and earlier | [CVE-2021-31571](https://nvd.nist.gov/vuln/detail/CVE-2021-31571), [CVE-2021-31572](https://nvd.nist.gov/vuln/detail/CVE-2021-31572) |

### Source Product Impact Details

- User applications built on FreeRTOS 10.4.1 or earlier which make calls to pvPortMalloc via API functions (MemMang, Queue, StreamBuffer) may be impacted. (Note: this applies to GSDK 3.0)

## Description

- [CVE-2021-31571](https://nvd.nist.gov/vuln/detail/CVE-2021-31571) and [CVE-2021-31572](https://nvd.nist.gov/vuln/detail/CVE-2021-31572) have been reserved for this issue.

- Additional information about this vulnerability is available at [CWE-190](https://cwe.mitre.org/data/definitions/190.html).

- [BadAlloc](https://us-cert.cisa.gov/ics/advisories/icsa-21-119-04) is a security vulnerability where inputs to heap memory allocation functions are not properly sanitized and integer overflow can cause large inputs to allocate small buffers.

### Fix/Workaround

- This has been fixed in FreeRTOS 10.4.2 and later. User applications using FreeRTOS should update to GSDK 3.1 or newer. GSDK 3.1 contains FreeRTOS 10.4.3. 
    1. In Simplicity Studio’s help menu, select the ‘Update Software’ menu item to open the Installation Manager.
    2. If working with Simplicity Studio v5, click ‘Manage installed packages’ to view the Product Updates. 
    3. Apply any required updates. 
    4. Select the ‘SDKs’ tab and choose the relevant stack(s) for your application then click the ‘Install’ button.
