# Silicon Labs Security Advisory A-00000345 : Security Advisory for NAME:WRECK Vulnerability on RS9116 running NETX

Flags: Security

CVSS Severity: Medium

CVSS Base Score: 6.5

CVSS Temporal Score: 5.7

CVSS String: CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:N/I:N/A:H/E:U/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| RS9116 SDK | 2.4.0 and earlier | - | - | - |

### Source Product Impact Details

- RS9116 SoCs and Modules 2.4.0 and earlier.

## Description

- A report published [here](https://www.forescout.com/research-labs/namewreck/) describes several DNS-related vulnerabilities. One of the impacted components, NETX, is included in the RS9116 SDK.

- A specially crafted DNS packet can lead to a denial-of-service.

### Fix/Workaround

- Upgrade the RS9116 SDK to version 2.4.1 or later from [https://docs.silabs.com/rs9116/](https://docs.silabs.com/rs9116/) to obtain the patched version of NETX.
