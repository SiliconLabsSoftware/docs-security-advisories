# Silicon Labs Security Advisory A-00000529 : Security advisory for CPC out of bounds read vulnerability

Flags: Security

CVSS Severity: Low

CVSS Base Score: 1.0, Low

CVSS Temporal Score: 1.0, Low

CVSS String: CVSS:4.0/AV:P/AC:H/AT:P/PR:N/UI:N/VC:L/VI:N/VA:N/SC:N/SI:N/SA:N

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| CPC daemon | 4.6.0 and earlier | SiSDK | 2024.12.0 and earlier | [CVE-2024-12975](https://nvd.nist.gov/vuln/detail/CVE-2024-12975) |

### Source Product Impact Details

- CPC-capable Linux hosts running CPC daemon version 4.6.0, and earlier, delivered as part of SiSDK 2024.12.0 using full-duplex SPI. 

Note: As of June 2024, the Gecko SDK was renamed to the Simplicity SDK and the versioning scheme was changed from Gecko SDK vX.Y.Z to Simplicity SDK YYYY.MM.Patch#.

## CVE ID(s)

- [CVE-2024-12975](https://nvd.nist.gov/vuln/detail/CVE-2024-12975) is reserved for this issue.

## Description

- An invalid packet received in full duplex mode SPI may cause the CPC daemon to read outside the bounds of the transmit buffer, possibly leading to a disclosure of sensitive information.
- A description of the Co-Processor Communication (CPC) product is found here [https://docs.silabs.com/d/platform-cpc-overview/4.3/](https://docs.silabs.com/d/platform-cpc-overview/4.3/)

### Fix/Workaround

- Impacted users should upgrade the CPC daemon to version 4.6.1, or later, delivered as part of SiSDK 2024.12.1.

- The latest version of CPC daemon is available at the following link [https://github.com/SiliconLabs/cpc-](https://github.com/SiliconLabs/cpc-) daemon/. Instructions for configuring and using the CPC daemon are available at the same link.

- This vulnerability was addressed in 4.6.1, [https://github.com/SiliconLabs/cpc-daemon/releases](https://github.com/SiliconLabs/cpc-daemon/releases)
