# Silicon Labs Security Advisory A-00000506 : Multiple DoS and RCE vulnerabilities in Gecko OS HTTP server

Flags: Security

CVSS Severity: High

CVSS String: Varies

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Gecko OS | - | - | - | [CVE-2025-2837](https://nvd.nist.gov/vuln/detail/CVE-2025-2837), [CVE-2024-23938](https://nvd.nist.gov/vuln/detail/CVE-2024-23938), [CVE-2024-24731](https://nvd.nist.gov/vuln/detail/CVE-2024-24731), [CVE-2024-24737](https://nvd.nist.gov/vuln/detail/CVE-2024-24737), [CVE-2024-23937](https://nvd.nist.gov/vuln/detail/CVE-2024-23937), [CVE-2024-23973](https://nvd.nist.gov/vuln/detail/CVE-2024-23973), [CVE-2024-2701](https://nvd.nist.gov/vuln/detail/CVE-2024-2701), [CVE-2024-24736](https://nvd.nist.gov/vuln/detail/CVE-2024-24736) |

### Source Product Impact Details

- WGM160P modules running all released versions of Gecko OS

## Description

See the following table for detailed technical descriptions of the vulnerabilities

| CVE | Technical summary | Type of Attack |
| --- | --- | --- |
| [CVE-2025-2837](https://nvd.nist.gov/vuln/detail/CVE-2025-2837), [CVE-2024-23973](https://nvd.nist.gov/vuln/detail/CVE-2024-23973) | A buffer-based overflow in the HTTP server allows an attacker to use a specially crafted GET request to gain remote code execution. | Remote code execution |
| [CVE-2024-23938](https://nvd.nist.gov/vuln/detail/CVE-2024-23938) | A buffer overflow vulnerability allows an attacker with access to the remote console to print a specially crafted debug message to gain remote code execution. | Remote code execution |
| [CVE-2024-24731](https://nvd.nist.gov/vuln/detail/CVE-2024-24731) | A buffer-based overflow in the HTTP client allows an attacker to request a file download from long URL which leads to remote code execution. | Remote code execution |
| [CVE-2024-24737](https://nvd.nist.gov/vuln/detail/CVE-2024-24737) | A specially crafted DNS response may lead to an infinite loop, causing a denial-of-service. | Denial of service |
| [CVE-2024-23937](https://nvd.nist.gov/vuln/detail/CVE-2024-23937) | A specially crafted URL causes the http_download command to leak information from the stack. | Information disclosure |

### Fix/Workaround

- Gecko OS is in end of life (EOL) status so no fix will be offered.
