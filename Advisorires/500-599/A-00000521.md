# Silicon Labs Security Advisory A-00000521 : Bluetooth denial of service vulnerabilities present in RS9116

Flags: Bluetooth

CVSS Severity: Medium

CVSS Base Score: 6.5 , Medium

CVSS Temporal Score: 5.9 , Medium

CVSS String: CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H/E:P/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| WiSeConnect SDK | 2.10.4 and earlier | - | - | [CVE-2024-7137](https://nvd.nist.gov/vuln/detail/CVE-2024-7137), [CVE-2024-7138](https://nvd.nist.gov/vuln/detail/CVE-2024-7138), [CVE-2024-7139](https://nvd.nist.gov/vuln/detail/CVE-2024-7139) |

### Source Product Impact Details

- Silicon Labs RS9116 products running the RS9116 WiSeConnect SDK 2.10.4 and earlier.
    - This issue only impacts Bluetooth Classic capable devices, SiWx917 is not impacted.

## CVE ID(s)

The following CVEs are reserved for this issue:

| CVE Number | Description |
| --- | --- |
| [CVE-2024-7137](https://nvd.nist.gov/vuln/detail/CVE-2024-7137) | DoS caused by an out of bounds write in RS9116 Bluetooth SDK |
| [CVE-2024-7138](https://nvd.nist.gov/vuln/detail/CVE-2024-7138) | DoS caused by an assert in RS9116 Bluetooth SDK |
| [CVE-2024-7139](https://nvd.nist.gov/vuln/detail/CVE-2024-7139) | DoS caused by an unchecked buffer length in RS9116 Bluetooth SDK |

## Description

- [CVE-2024-7137](https://nvd.nist.gov/vuln/detail/CVE-2024-7137)
    - A denial of service may be caused due to improper receive data length restrictions.
    - A hard reset is required to recover the device.
- [CVE-2024-7138](https://nvd.nist.gov/vuln/detail/CVE-2024-7138)
    - An assert is triggered, causing a temporary denial of service when a peer device sends multiple L2CAP echo requests in a single frame.
    - A hard reset is required to recover the device.

- [CVE-2024-7139](https://nvd.nist.gov/vuln/detail/CVE-2024-7139)
    - An unchecked buffer length triggers an assert, which results in a temporary denial of service.
    - A hard reset is required to recover the device.

### Fix/Workaround

- To mitigate the issues, impacted users should upgrade to WiSeConnect SDK 2.11 or later, delivered as an extension of the SiSDK 2024.12.0. Instructions for updating firmware on RS9116 can be found in AN1290.

- Instructions for [updating the SiSDK](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-about-the-launcher/toolbar#install) and for [upgrading a project to a new SiSDK version](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) can be found in the Simplicity Studio Users Guide.
