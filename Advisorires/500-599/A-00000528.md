## CVE ID(s)

- The following CVE has been published for this vulnerability [CVE-2023-52160](https://nvd.nist.gov/vuln/detail/CVE-2023-52160)

## Description

- The implementation of the PEAP protocol in wpa_supplicant allows an authentication bypass.

### Fix/Workaround

- Impacted SiWx917 users should upgrade to WiseConnect 3.4.1, or later and take advantage of the PEAPSAFE-1 or PEAPSAFE-2 feature, see link to instructions below.

- Impacted RS9116 users should upgrade to WiseConnect 2.11.4, or later later and take advantage of the PEAPSAFE-1 or PEAPSAFE-2 feature, see link to instructions below.

- Instructions for [updating the Simplicity SDK](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-about-the-launcher/toolbar#install) and for [upgrading a project to a new Simplicity SDK version](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) can be found in the Simplicity Studio Users Guide

- Please refer to the [WiSeConnect](https://github.com/SiliconLabs/wiseconnect/blob/master/docs/release-notes/index_soc.md) release notes for more information for the fix implemented

- Instructions on the use of the PEAPSAFE-1 and PEAPSAFE2 things can be found here [https://community.silabs.com/s/article/Understanding-EAP-PEAP-Authentication-and-Its-Vulnerabilities?language=en_US](https://community.silabs.com/s/article/Understanding-EAP-PEAP-Authentication-and-Its-Vulnerabilities?language=en_US)
