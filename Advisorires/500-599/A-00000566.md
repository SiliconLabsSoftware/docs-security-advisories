## Description

- A reachable infinite loop is present in Silicon Labs Matter SDK when using GetThreadMetrics command
    - This allows an attacker to trigger a denial of service of the device, requiring a hard reset to recover the device

- A few conditions are required to exploit this vulnerability:
    - The malicious device must be commissioned in the Matter network
        - The target device must have an ACL with the malicious device to accept these commands
    - The device under attack must have more than 255+ concurrent tasks running
        - By default, no example applications released by Silicon Labs implement running 255+ concurrent tasks

### Fix/Workaround

- The vulnerability was addressed in Silicon Lab’s Matter SDK Extension 2.8.0, delivered as part of SiSDK 2025.12.0. Impacted users should upgrade to this version or later to include the fix.

- Instructions for updating extensions can be found [here](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version#upgrading-to-a-new-extension).
