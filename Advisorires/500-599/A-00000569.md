## Description

- This advisory is intended for users of the Gecko SDK, Simplicity SDK, and WiseConnect SDK, regarding the third-party lwIP library included in these SDKs. This library contains two vulnerabilities that have been resolved in lwIP 2.1.3. Please refer to the associated CVEs for detailed information

### Fix/Workaround

- Affected users should upgrade to SDK versions that include the fixes for these vulnerabilities

    - WiseConnect users should upgrade to WiseConnect SDK version 4.0.0 or later

    - For Simplicity SDK and Gecko SDK users should upgrade to SiSDK version 2026.6.0 or later

- Instructions for [downloading/updating the WiseConnect SDK](https://docs.silabs.com/wiseconnect/latest/wiseconnect-developers-guide-developing-for-ics-or-modules/) can be found in the WiseConnect Developer’s Guide

- Instructions for [downloading/updating the SDK](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-about-the-launcher/toolbar#install) and for [upgrading a project](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) can be found in the Simplicity Studio Users Guide.
