# Silicon Labs Security Advisory A-00000500 : Uninitialized TRNG used for ECDSA signing after EM2/EM3 sleep for VSE devices

Flags: Security

CVSS Severity: Medium

CVSS Base Score: 6.8, Medium

CVSS Temporal Score: 6.5, Medium

CVSS String: CVSS:3.1/AV:N/AC:H/PR:N/UI:N/S:C/C:N/I:H/A:N/E:H/RL:O/RC:C

## CVE ID(s)

- This vulnerability is tracked by [CVE-2024-22473](https://nvd.nist.gov/vuln/detail/CVE-2024-22473) [1]

## Description

- Due to a bug in the ECDSA signing driver for Virtual Secure Engine (VSE) devices, the True Random Number Generator (TRNG) may be uninitialized when used to perform an ECDSA signature after coming out of EM2/EM3 reset.

- This bug causes predictable, repeating NONCEs to be used for ECDSA signatures, which may result in a loss of private signing key material

- The bug was caused by an internal signing function that retrieved bytes directly from the underlying TRNG block, bypassing the proper use of psa_generate_random, which initializes the TRNG before its utilization.

- This internal signing function is used by: psa_sign_message, psa_sign_hash, psa_initial_attest_get_token, and sl_sec_man_sign

- A VSE device is impacted only if it comes out of EM2/EM3 and uses any affected APIs prior to calling either either psa_generate_random or psa_generate_key

- This vulnerability only affects signing/attestation and does not impact verification of ECDSA.

### Fix/Workaround

- VSE devices should be updated to GSDK version 4.4.1 or later
- Instructions for downloading/updating the GSDK [2] and for upgrading a project to use a new GSDK version [3] can be found in the Simplicity Studio Users Guide
- Consult the following table for mitigation steps for affected devices:

| Part | SDK Version | Bug ID | Release Notes |
| --- | --- | --- | --- |
| EFM32PG22C EFR32xG22C EFR32xG27C EFR32MG22A | Upgrade to 4.4.1 or later | 1244117 | GSDK 4.4.1 [4] |

- If an SDK update is not possible, this vulnerability can be mitigated by ensuring psa_generate_random or psa_generate_key are always called before an impacted API is used
