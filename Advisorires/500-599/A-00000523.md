## Description

- Vulnerabilities present in the MAC, Network, and APS layers of the Zigbee stack can trigger an assert, leading to a DoS, when a malformed packet is sent.

- Each of these conditions leads to system reset via the watchdog, immediately restoring normal operation.

### Fix/Workaround

- Users affected by [CVE-2024-6350](https://nvd.nist.gov/vuln/detail/CVE-2024-6350) or [CVE-2024-6352](https://nvd.nist.gov/vuln/detail/CVE-2024-6352) should upgrade to Ember ZNet SDK 8.1.0, or later delivered as part of SiSDK 2024.12.0, or later.
- Users affected by [CVE-2024-6351](https://nvd.nist.gov/vuln/detail/CVE-2024-6351) should upgrade to Ember ZNet SDK 8.2.0, or later delivered as part of SiSDK 2025.6.0, or later.

- Users of EmberZNet 7.4.5, and earlier, delivered as part of Gecko SDK 4.4.5, and earlier should upgrade to EmberZNet 7.5.0, or later, delivered as part of Gecko SDK 4.4.6 or later to mitigate all three CVEs mentioned in this advisory.

- Instructions for [downloading/updating the SDK](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-about-the-launcher/toolbar#install) and for [upgrading a project](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) can be found in the Simplicity Studio Users Guide.
