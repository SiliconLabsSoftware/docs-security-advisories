# Silicon Labs Security Advisory A-00000493 : Long S0 frames received by Z-Wave 500 Series devices may cause buffer overflow

### Source Product Impact Details

- All Z-Wave 500 Series Silicon Labs products

## CVE ID(s)

- [CVE-2024-22472](https://nvd.nist.gov/vuln/detail/CVE-2024-22472) [1] is reserved for this vulnerability

## Description

- A missing length check allows a stack overflow on Z-Wave 500 Series devices, however due to the memory architecture of Z-Wave 500 Series devices, this vulnerability does not permit arbitrary code execution unless Execute out of SRAM (EooS) mode is enabled [2].
- Even if EooS is disabled, an attacker may be able to exploit this vulnerability using Return-oriented Programming to gain control of firmware execution flow, thereby allowing the attacker to execute valid code already installed on the device.
- During validation testing of this issue, long S0 frames were determined to cause a crash in Z-Wave 500 Series devices, enabling a potential DoS.

### Fix/Workaround

- To harden against remote code execution on impacted devices, customers should not enable EooS, which is disabled by default.
- Affected Z-Wave 500 Series customers should update to Z-Wave 500 Series SDK 6.85.2 or later
- Instructions for updating Z-Wave 500 Series devices can be found in INS12366-Working-In-500-Series- Environment-Users-Guide [3].
