# Silicon Labs Security Advisory A-00000416 : Heap-based buffer overflow in Micrium OS HTTP Server allows potential remote code execution

Flags: Wi-Fi, MCU

CVSS Severity: High

CVSS Base Score: 9.1, High

CVSS Temporal Score: 8.3, High

CVSS String: CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:H/A:H/E:P/RL:U/RC:R

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Micrium OS Network | 4.1.0 and earlier | GSDK | 4.1.0 and earlier | - |

### Source Product Impact Details

- WGM1x0 and WF200 SoC’s and modules running Micrium OS 4.1.0 (associated with GSDK 4.1.0) or earlier may be impacted

- EFR32 and EFM32 SoC’s and modules running the Wi-Fi stack of Micrium OS 4.1.0 (associated with GSDK 4.1.0) or earlier may be impacted

## Description

- A heap-based buffer overflow vulnerability exists in the HTTP Server functionality of Micrium OS 4.1.0 and earlier, such that an HTTP request can be specially crafted to cause a heap overflow. Depending on how the Micrium memory allocator is used in the server, this could potentially result in remote code execution, although it is unlikely.

- An attacker within the network can send an HTTP request to trigger this vulnerability.

### Fix/Workaround

- Affected users should upgrade to Micrium OS 4.1.1 (distributed with GSDK 4.1.1) or later. 
    1. In Simplicity Studio’s Help menu, select the ‘Update Software’ menu item to open the Installation Manager 
    2. Click the ‘Manage installed packages’ button 
    3. Select the ‘SDKs’ tab and find the ‘Gecko SDK – 32-bit and Wireless MCUs’ section 
    4. If there are not currently any Installations, click the ‘Install New’ button. If there is an SDK already installed, click on the ‘...’ button next to its version number 
    5. Click ‘Change Version’
    6. In the ‘Versions:’ dropdown menu, select the desired version
    7. Click ‘FINISH’
