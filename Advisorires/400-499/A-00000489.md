# Silicon Labs Security Advisory A-00000489 : Matter out of bounds write vulnerabilities

Flags: Matter

CVSS Severity: Low

CVSS Base Score: 2.1, Low

CVSS Temporal Score: 2.0, Low

CVSS String: CVSS:3.1/AV:A/AC:L/PR:H/UI:R/S:U/C:N/I:N/A:L/E:F/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Silicon Labs Matter | 2.1.x and earlier | GSDK | 4.3.1 and earlier | - |

### Source Product Impact Details

- All products running CSA Matter SDK 1.1.x (Silicon Labs Matter Github 2.1.x, Matter GSDK Extension 4.3.x) and earlier are affected.

## CVE ID(s)

- No CVEs were reserved by the CSA for these vulnerabilities.

## Description

- These two vulnerabilities occur during the Matter commissioning process. Devices that are not in commissioning mode are not known to be vulnerable to this issue. Initiating Matter commissioning requires knowledge of the device’s Matter passcode.

- Two distinct out of bounds writes may occur due to improper length checking when extracting TLV data during the device commissioning process. Each of these out of bounds writes can cause stack corruptions, which could lead to a denial of service.

### Fix/Workaround

- These vulnerabilities were mitigated in Silicon Labs Matter Github 2.2.0 [1] (CSA Matter SDK 1.2.0, Matter GSDK Extension 4.4.0). Affected users should update to GSDK 4.4.0 or later. Instructions for downloading or updating the GSDK [2] and upgrading to a new Matter Extension [3] can be found in our developer documentation.
    - Please note that due to the large scope of code changes between CSA Matter SDK 1.1.x and CSA Matter SDK 1.2.0, additional manual steps are required to upgrade an existing Simplicity Studio project to Matter Extension version 2.2.0, in GSDK 4.4.0. These steps are outlined in the “Known Issues” section of the Silicon Labs Matter release notes [4].
