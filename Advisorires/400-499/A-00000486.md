# Silicon Labs Security Advisory A-00000486 : Z/IP Gateway use of uninitialized PRNG when generating S0 encryption key

Flags: Z-Wave

CVSS Severity: Medium

CVSS Base Score: 6.4, Medium

CVSS Temporal Score: 6.3, Medium

CVSS String: CVSS:3.1/AV:P/AC:H/PR:N/UI:N/S:U/C:H/I:H/A:H/E:H/RL:W/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Z/IP Gateway SDK | 7.18.3 and earlier | - | - | [CVE-2023-4489](https://nvd.nist.gov/vuln/detail/CVE-2023-4489) |

### Source Product Impact Details

- All Z/IP Gateway products running Z/IP Gateway SDK 7.18.3 and earlier booting with an S0 key generated during startup.

## CVE ID(s)

- [CVE-2023-4489](https://nvd.nist.gov/vuln/detail/CVE-2023-4489) [1] is reserved for this issue.

## Description

- For S0 keys, the pseudo-random number generator (PRNG) remains uninitialized at startup, which results in the S0 key being predictable. This issue only impacts devices with the first key generated at boot time.

### Fix/Workaround

- The issue can be mitigated by using either of the two methods listed below.
    - A default set command can be issued to the Z/IP Gateway to reset the S0 network key before putting the controller device into service. This command can be issued by the Z-Wave PC Controller included in Simplicity Studio tools. Once the Z-Wave PC Controller window is open, click on the “Network Management” button to bring up your connected controller. Next, click on the “Reset” button to reset the predictable network key to a new key using the properly initialized PRNG.
    - The S0 key can be written to NVM3 before starting the Z/IP Gateway. Please refer to Section 6.15.4 and Section 6.15.5 of the Simplicity Commander User Guide, UG162 [2], for more information on writing data to NVM3.

- While it is likely that a fix will be released in the future, there is currently no committed release date for a fix. For more information, check the release notes for future SDK releases.
