# Silicon Labs Security Advisory A-00000499 : Bluetooth LE denial of service when handling multiple connections

Flags: Bluetooth

CVSS Severity: Medium

CVSS Base Score: 6.5, Medium

CVSS Temporal Score: 5.9, Medium

CVSS String: CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H/E:P/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Bluetooth LE SDK | 5.x and earlier | GSDK | 4.2.x and earlier | [CVE-2024-0240](https://nvd.nist.gov/vuln/detail/CVE-2024-0240) |

### Source Product Impact Details

- Bluetooth LE-capable EFR32xGxx SoCs and associated modules running Bluetooth SDK earlier than 6.0.0, delivered as part of GSDK 4.3.0 and earlier

## CVE ID(s)

- [CVE-2024-0240](https://nvd.nist.gov/vuln/detail/CVE-2024-0240)[1] is reserved for this issue

## Description

- A Bluetooth LE server capable of sending notifications for at least one GATT characteristic may experience a denial of service when sending notifications to multiple clients

- A memory leak may cause all Bluetooth operations, such as advertising and scanning, to stop

- A reset of the device immediately clears the fault

### Fix/Workaround

- Affected users should upgrade to Bluetooth SDK 6.0.0, or later delivered as part of Gecko SDK 4.3.0, or later. Instructions for downloading/updating the GSDK can be found in the Simplicity Studio Users Guide here Simplicity Studio User's Guide [2]
- This issue is tracked as bug id #1124749 in Release notes[3]
