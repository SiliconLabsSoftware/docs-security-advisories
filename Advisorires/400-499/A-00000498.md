# Silicon Labs Security Advisory A-00000498 : Potential DoS due to resource depletion in high traffic Zigbee environments

Flags: Zigbee

CVSS Severity: Medium

CVSS Base Score: 5.3, Medium

CVSS Temporal Score: 4.8, Medium

CVSS String: CVSS:/3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:L/E:P/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| EmberZNet | 7.3.x and earlier | GSDK | 4.3.x and earlier | [CVE-2023-51394](https://nvd.nist.gov/vuln/detail/CVE-2023-51394), [CVE-2023-51392](https://nvd.nist.gov/vuln/detail/CVE-2023-51392) |

### Source Product Impact Details

- All devices running EmberZnet SDK prior to version 7.4.0.0 (GSDK 4.4.0)

## CVE ID(s)

- This vulnerability is tracked by [CVE-2023-51394](https://nvd.nist.gov/vuln/detail/CVE-2023-51394) [1].

## Description

- In a high traffic environment, a buffer pool can be depleted in end nodes leading to an exception and device reset.

- The device is unavailable until it reboots and rejoins the network.

### Fix/Workaround

- Affected users should upgrade to Gecko SDK 4.4.0, or later.

- Instructions for downloading/updating the GSDK [2] and for upgrading a project to use a new GSDK version [3] can be found in the Simplicity Studio Users Guide.

- The mitigation for this vulnerability has also been backported to the branches appearing in the following table under “Mitigated Versions.”

| Branch | Mitigated Version |
| --- | --- |
| GSDK 4.2.x | GSDK 4.2.5 or later |
| GSDK 4.4.x | GSDK 4.4.0 or later |
