# Silicon Labs Security Advisory A-00000479 : Vulnerability in Silabs implementation of Zigbee TouchLink

Flags: Zigbee

CVSS Severity: Medium

CVSS Base Score: 5.9, Medium

CVSS Temporal Score: 5.7, Medium

CVSS String: CVSS:3.1/AV:A/AC:H/PR:N/UI:R/S:U/C:L/I:L/A:H/E:H/RL:O/RC:C

## Description

- This vulnerability is tracked by [CVE-2023-41094](https://nvd.nist.gov/vuln/detail/CVE-2023-41094)

- Due to a feature added in Ember ZNet 7.1.3, a bug was introduced that caused Ember ZNet to accept packets outside of Zigbee Link Layer range.

- This bug also affects a TransactionID timeout in TouchLink processing, potentially allowing processing of expired/relayed packets

- This vulnerability causes TouchLink packets to be processed even when a device is outside of the maximum pairing range governed by the Zigbee specification
- Attackers exploiting this vulnerability may be able to get devices to join or leave a TouchLink network without authorization

### Fix/Workaround

- The recommended mitigation is to update to Ember Znet 7.3.0 or later, (GSDK 4.3.1 or later). However, in the event an upgrade is impossible, the following branches appearing in the table below have additionally been patched for this vulnerability:

Table 1 - Mitigated Branches

| Affected Version | Patched Version | Reference No. | Release Notes |
| --- | --- | --- | --- |
| GSDK 4.1.x | GSDK 4.1.6 | 1172844 | Ember ZNet 7.1.6.0 Release Notes |
| GSDK 4.2.x | GSDK 4.2.4 | 1174328 | Ember ZNet 7.2.4.0 Release Notes |
| GSDK 4.3.x | GSDK 4.3.1 | 1157289 | Ember ZNet 7.3.1.0 Release Notes |

- Instructions for downloading/updating the GSDK and for upgrading a project to use a new GSDK version can be found in the Simplicity Studio Users Guide

## Certification Impact

- Devices with this vulnerability present fail Zigbee Certification test case DN-TLM-TC-02B
- This vulnerability must be mitigated to attain certification
