# Silicon Labs Security Advisory A-00000478 : Security advisory for Gecko Bootloader integer overflow vulnerability

Flags: Security

CVSS Severity: Medium

CVSS Base Score: 4.4, Medium

CVSS Temporal Score: 4.0, Medium

CVSS String: CVSS:3.1/AV:L/AC:L/PR:L/UI:N/S:U/C:L/I:L/A:N/E:P/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Gecko Bootloader | 2.3.1 and earlier | GSDK | 4.3.1 and earlier | [CVE-2023-3487](https://nvd.nist.gov/vuln/detail/CVE-2023-3487) |

### Source Product Impact Details

- All EFx32- based SoCs and associated modules running Gecko Bootloader, delivered as part of Gecko SDK 4.3.1 and earlier may be impacted.

## Description

- An integer overflow can lead to unbounded memory access when reading from or writing to storage slots.

- Bootloaders that use storage slots are impacted.

- [CVE-2023-3487](https://nvd.nist.gov/vuln/detail/CVE-2023-3487) has been reserved for this issue and can be found at the following link: [https://nvd.nist.gov/vuln/detail/CVE-2023-3487](https://nvd.nist.gov/vuln/detail/CVE-2023-3487).

- This issue is tracked in the release notes for GSDK version 4.3.2, found here: [https://www.silabs.com/developers/gecko-software-development-kit](https://www.silabs.com/developers/gecko-software-development-kit), as bug id # 1170458.

### Fix/Workaround

- Affected users should update to GSDK 4.3.2 or later. Instructions for downloading/updating the GSDK can be found in the Simplicity Studio Users Guide here: [https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version)
