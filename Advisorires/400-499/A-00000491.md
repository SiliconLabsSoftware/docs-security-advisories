# Silicon Labs Security Advisory A-00000491 : Micrium OS Network uC-TCP-IP Denial of Service Vulnerabilities

Flags: Security

CVSS Severity: Medium

CVSS Base Score: 5.9, Medium

CVSS Temporal Score: 5.1, Medium

CVSS String: CVSS:3.1/AV:N/AC:H/PR:N/UI:N/S:U/C:N/I:N/A:H/E:P/RL:O/RC:R

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Micrium OS Network | 5.15.1 and earlier | GSDK | 4.4.0 and earlier | [CVE-2023-39540](https://nvd.nist.gov/vuln/detail/CVE-2023-39540), [CVE-2023-39541](https://nvd.nist.gov/vuln/detail/CVE-2023-39541) |

### Source Product Impact Details

- EFx32x using uC-TCP-IP from Micrium OS Network in GSDK 4.3.1 and earlier are affected
- Devices not using uC-TCP-IP from Micrium OS Network are unaffected

## Description

[CVE-2023-39540](https://nvd.nist.gov/vuln/detail/CVE-2023-39540)– uC-TCP-IP ICMPv4 parsing denial of service vulnerability
- ICMPv4 processing code in Micrium OS Network has a potential unmapped memory access that may cause a crash when processing malformed ICMPv4 headers
- An attacker can send a specially crafted ICMPv4 packet to trigger this vulnerability, potentially causing a denial of service 

[CVE-2023-39541](https://nvd.nist.gov/vuln/detail/CVE-2023-39541)– uC-TCP-IP ICMPv6 parsing denial of service vulnerability
- ICMPv6 processing code in Micrium OS Network has a potential unmapped memory access that may cause a crash when processing malformed ICMPv6 headers
- An attacker can send a specially crafted ICMPv6 packet to trigger this vulnerability, potentially causing a denial of service

### Fix/Workaround

- Affected users should update Micrium OS Network to 5.15.2 or higher (included in GSDK 4.4.1 or later)
- Instructions for downloading/updating the GSDK and for upgrading a project to use a new GSDK version can be found in the Simplicity Studio Users Guide
- These vulnerabilities can also be mitigated without upgrading GSDK by enabling NET_ERR_CFG_ARG_CHK_DBG_EN in platform/micrium_os/cfg/net_cfg.h and issuing a ‘Make Clean’ and ‘Make’ to recompile affected projects
- The following SDK releases address these vulnerabilities. Customers are always encouraged to update to the latest SDK version available
