# Silicon Labs Security Advisory A-00000085 : Bluetooth Message Integrity Check (MIC) weakness in Gecko SDK versions 2.7.2 and earlier on EFR32xG21 devices.

Flags: Bluetooth

CVSS Severity: Low

CVSS Base Score: 4.0 Medium

CVSS Temporal Score: 3.7 Low

CVSS String: CVSS:3.1/AV:L/AC:L/PR:N/UI:N/S:U/C:N/I:H/A:N/E:F/RL:O/RC:C

| Product | Impacted Version | Main SDK | Impacted Version | CVE |

### Source Product Impact Details

- EFR32xG21 devices running Bluetooth Stack 2.13.2 or earlier in Gecko SDK versions 2.7.2 and earlier

- EFR32BG21 Series 2 Bluetooth® Wireless SoCs
- EFR32BG21 Series 2 Modules
- EFR32MG21 Series 2 Multiprotocol Wireless SoCs
- EFR32MG21 Series 2 Modules

## Description

- Bluetooth uses AES-CCM for encryption and authentication. Each packet is tagged with a 32-bit authentication code. The receiver must validate the authentication code on reception. This process verifies that the packet has not been modified in transit, and is known as a Message Integrity Check (or MIC).
- If the MIC value on a packet is invalid, the connection will immediately be disconnected.
- EFR32xG21 devices running the Bluetooth Stack in older Gecko SDK versions only check the first 8-bits of the authentication tag. This makes it possible for an attacker to send a packet with a random MIC value, and have a 1-in-256 chance of the packet being authenticated as valid.
- Since the Message Integrity Check is used for authentication of the encrypted packet, but not for confidentiality, this vulnerability does not help an attacker decrypt the content of packets, nor does it help an attacker construct a specific payload for a malicious packet.

### Fix/Workaround

- This vulnerability has been patched in Bluetooth SDK version 2.13.3 included in Gecko SDK version 2.7.3 onwards, including Gecko SDK version 3.0.0.
- Devices running older versions of the Bluetooth stack should be updated. Upgrade instructions can be found in [AN1086: Using the Gecko Bootloader with the Silicon Labs Bluetooth® Applications.](https://www.silabs.com/documents/public/application-notes/an1086-gecko-bootloader-bluetooth.pdf)
