# Silicon Labs Security Advisory A-00000058 : Denial of service vulnerability in Bluetooth LE in EFR32 SoC’s and associated modules supporting Central or Observer roles

Flags: Bluetooth

CVSS Severity: Medium

CVSS String: [CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H/E:F/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H/E:F/RL:O/RC:C)

## Product Impact

EFR32 SoC’s and associated modules running Bluetooth SDK version 2.13.2 or earlier supporting Central or Observer roles 

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| ------- | ---------------- | -------- | ---------------- | --- |
| Bluetooth LE SDK | 2.13.2 and earlier | GSDK | 2.7.2 and earlier | [CVE-2020-15532](https://nvd.nist.gov/vuln/detail/CVE-2020-15532) |

## Description

- A malicious advertising packet received over Bluetooth LE in extended scanning mode can result in a memory access violation resulting in denial of service

- The specific implementation of this attack will not be disclosed

- Reference: [CVE-2020-15532](https://nvd.nist.gov/vuln/detail/CVE-2020-15532)

### Fix/Workaround

- This vulnerability has been patched (Bug ID #466477) in Bluetooth SDK version 2.13.3 included in GSDK
version 2.7.3.

- Devices running older versions of the Bluetooth stack should be updated. Upgrade instructions can be
found in [AN1086: Using the Gecko Bootloader with the Silicon Labs Bluetooth® Applications](https://www.silabs.com/documents/public/application-notes/an1086-gecko-bootloader-bluetooth.pdf).
