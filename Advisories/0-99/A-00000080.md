# Silicon Labs Security Advisory A-00000080 : This document describes two security vulnerabilities in WF200 Wi-Fi devices and WFM200 modules. The related Product Change Notification (PCN) for these issues is [#200922853](https://www.silabs.com/documents/public/pcns/200922853-WF200WFM200S-New-Revision-Parts-and-Datasheets-Available.pdf).

Flags: Wi-Fi

CVSS Severity: Medium

CVSS String: [CVSS:3.1/AV:P/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H/E:U/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:P/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H/E:U/RL:O/RC:C)

# Issue 1 - Secure Boot

A vulnerability in Secure Boot could allow arbitrary code execution in WF200 Wi-Fi devices and WFM200 modules

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| WF200 devices and WFM200 SIP modules | - | - | - | - |

### Source Product Impact Details

- WF200 devices and WFM200 SIP modules with the following part numbers:
    - WF200C, WF200SC, WFM200S022XNA2, WFM200S022XNN2, WFM200SS22XNA2, and WFM200SS22XNN2

## Description

- An attacker with intimate knowledge of the physical design could potentially bypass Secure Boot and achieve unauthorized code execution by physically exploiting the NCP/host interface

### Fix/Workaround

- WF200 devices and WFM200 modules have been updated to fix this issue. Fixed part numbers:

    - WF200D, WF200SD, WFM200S022XNA3, WFM200S022XNN3, WFM200SS22XNA3, and WFM200SS22XNN3

# Issue 2 - Secure Link

A vulnerability in Secure Link could expose the contents of secured management frames and host/transceiver connection information in WF200 Wi-Fi devices and WFM200 modules

### Source Product Impact Details

- Secure Link enabled WF200 devices and WFM200 SIP modules with the following part numbers:
    - WF200SC, WFM200SS22XNA2, and WFM200SS22XNN2

## Description

- An attacker with physical access to the NCP/host interface could potentially read some unencrypted contents of management frames or host/transceiver connection information even if Secure Link is enabled. Because the attacker does not have control over which information is potentially leaked, this vulnerability results in a low impact to confidentiality.

- Note that Secure Link is not recommended to secure application payload data for performance reasons, as application payload data is assumed to already be encrypted before it is presented to the device.

### Fix/Workaround

- WF200 devices and WFM200 modules have been updated to fix this issue. Fixed part numbers:
    - WF200SD, WFM200SS22XNA3, and WFM200SS22XNN3
