# Silicon Labs Security Advisory A-00000089 : BLURtooth security vulnerability using cross transport key derivation in devices supporting both Bluetooth Classic and Bluetooth Low Energy

Flags: Bluetooth

CVSS Severity: Medium

CVSS Base Score: 5.9, medium

CVSS Temporal Score: 5.3, medium

CVSS String: [CVSS:3.1/AV:N/AC:H/PR:N/UI:N/S:U/C:N/I:H/A:N/E:P/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:N/AC:H/PR:N/UI:N/S:U/C:N/I:H/A:N/E:P/RL:O/RC:C)

### Source Product Impact Details

- No Silicon Labs’ products are affected by this vulnerability

- The EFR32 and BLE1xx SoCs and modules do not support CTDK since only Bluetooth LE is available on these devices

- The BT121 module is compliant with Bluetooth 4.1 which does not define the CTDK feature

- The RS9113/RS9116 SoCs and modules do comply with Bluetooth 4.2 which defines the CTDK feature, but do not implement the feature.

## Description

- A Bluetooth feature known as cross transport key derivation (CTDK) can be used to bypass security in an affected device. Only devices supporting both Bluetooth classic and Bluetooth Low Energy are affected.

- The Bluetooth SIG has issued the following advisory: [https://www.bluetooth.com/learn-about-bluetooth/bluetooth-technology/bluetooth-security/blurtooth/](https://www.bluetooth.com/learn-about-bluetooth/bluetooth-technology/bluetooth-security/blurtooth/)

- The CERT co-ordination center has issued the following advisory [https://kb.cert.org/vuls/id/589825](https://kb.cert.org/vuls/id/589825)

- No Silicon Labs products implement the optional CTDK feature

### Fix/Workaround

- No action is required for any Silicon Labs products on this vulnerability
