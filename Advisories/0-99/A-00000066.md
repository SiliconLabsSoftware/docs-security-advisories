# Silicon Labs Security Advisory A-00000066 : Buffer overflow vulnerability in Big Endian NCP hosts running EmberZNet 6.7.3 or earlier could result in remote code execution

Flags: Zigbee

CVSS Severity: High

CVSS String: CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H/E:U/RL:O/RC:C

## Product Impact

Big Endian NCP hosts running EmberZNet 6.7.3 or earlier, distributed in GDSK 2.7.3 or earlier

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| ------- | ---------------- | -------- | ---------------- | --- |
| EmberZNet | 6.7.3 and earlier | GSDK | 2.7.3 and earlier | - |

## Description

- Big Endian hosts receiving an over-the-air Write Attribute Request could trigger a buffer overrun resulting in remote code execution

- The specific implementation of this attack will not be disclosed

### Fix/Workaround

- This vulnerability has been patched (Bug ID#467374) in EmberZNet 6.7.4, GDSK 2.7.4 or later.

- Affected NCP hosts running older versions of EmberZNet are recommended to upgrade to a patched certified version such as EmberZNet 6.7.5 distributed in GSDK 2.7.5 or later or GSDK 3.0.0 or later.
