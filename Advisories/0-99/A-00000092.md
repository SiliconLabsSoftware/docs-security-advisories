### Source Product Impact Details

- Any EFR32 based SoC or module supporting Bluetooth LE and running SDK version 2.13.7 or earlier and 3.0.0 or 3.0.1.

- BLE112, BLE113, BLE121LR and BLED112 modules running SDK 1.9.0 or earlier.

- BT121 modules running SDK 1.5.0 or earlier.

- RS9116 SoCs and modules running SDK version 2.4.1 and earlier.

- RS9113 – all versions

Note: This is an update to security advisory A-00000092. The changes are to
1. Specify the fix for RS9116
2. Indicate that no fix will be done for the EOL product RS9113

## Description

- Three vulnerabilities, collectively known as BlueMirror, have been identified in the Bluetooth protocol’s pairing mechanism.

- These vulnerabilities are being tracked by CERT as [VU#799380](https://www.kb.cert.org/vuls/id/799380) and are summarized in the following table:

| Issue # | Description | CVE # | CVSS Severity | CVSS Vector |
| --- | --- | --- | --- | --- |
| 1 | Impersonation attack on the passkey entry protocol through reflection of public keys and nonces | [CVE-2020-26558](https://nvd.nist.gov/vuln/detail/CVE-2020-26558) | Medium | [CVSS:3.1/AV:A/AC:L/PR:N/UI:R/S:U/C:L/I:L/A:N](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:A/AC:L/PR:N/UI:R/S:U/C:L/I:L/A:N)
| 2 | Attack on LE legacy pairing protocol using reflection of public keys and nonces. This attack does not compromise availability, confidentiality or integrity but could be combined with another unknown attack to establish an encrypted connection | N/A | None | [CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:N](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:N) 
| 3 | Impersonation attack on the PIN pairing procedure in BR/EDR through reflection of public keys and nonces | [CVE-2020-26555](https://nvd.nist.gov/vuln/detail/CVE-2020-26555) | Medium | [CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:L/I:L/A:N](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:L/I:L/A:N) |

### Fix/Workaround

- For EFR32, upgrade to 2.13.8 or later if using GSDK 2.x or upgrade to 3.0.2 or later if using GSDK 3.x. Upgrades are performed using the installation manager. In Simplicity Studio, go to the help menu and select the ‘update software’ menu item. Click the ‘manage installed packages’ button, select the SDKs tab, find the ‘Bluetooth SDK’ section and click the ‘Update’ button.

- For BLE112, BLE113, BLE121LR and BLED112 upgrade to SDK 1.10 or later. The installation utility is available [here](https://www.silabs.com/documents/login/software/Bluegiga_ble-1.10.0-153.exe).

- For BT121 upgrade to SDK 1.6.0 or later. The installation utility is available here.

- For RS9116 impacted users should upgrade to WiSeConnect 2.5.0, or later. The WiSeConnect SDK is available for download at [https://github.com/SiliconLabs/wiseconnect-wifi-bt-sdk/](https://github.com/SiliconLabs/wiseconnect-wifi-bt-sdk/)

- RS9113-based products have reached end-of-life status and will not receive any mitigation for this vulnerability.
