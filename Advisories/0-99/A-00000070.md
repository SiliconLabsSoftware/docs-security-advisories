# Silicon Labs Security Advisory A-00000070 : Remote code execution vulnerability in Silicon Labs WFx Wi-Fi FMAC driver version 3.0.3

Flags: Wi-Fi

CVSS Severity: Medium

CVSS Base Score: 7.6 High

CVSS Temporal Score: 6.8 Medium

CVSS String: CVSS:3.1/AV:P/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H/E:P/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| WF200 Series 2 Wi-Fi Transceiver Modules / SoCs and WGM160 Series 1 Wi-Fi Modules | 3.03 and earlier | - | - | - |

### Source Product Impact Details

- WF200 Series 2 Wi-Fi Transceiver Modules / SoCs and WGM160 Series 1 Wi-Fi Modules interfacing to host processors running Silicon Labs Wfx Wi-Fi FMAC driver version 3.03 or below. ([https://github.com/SiliconLabs/wfx-fullMAC-driver](https://github.com/SiliconLabs/wfx-fullMAC-driver))

## Description

- An attacker with physical access to a device’s SPI/SDIO bus can generate a malformed WFX response frame that will corrupt memory in the host processor, potentially allowing remote code execution on the host.

### Fix/Workaround

- This vulnerability has been patched in the WFx Wi-Fi FMAC driver, version 3.0.4 as of 7/21/2020.

- Devices running older versions of the WFx Wi-Fi FMAC driver should be updated. Instructions on building and installing the latest FMAC WFx00 series driver can be found here: [https://github.com/SiliconLabs/wfx-](https://github.com/SiliconLabs/wfx-) fullMAC-driver
