# Silicon Labs Security Advisory A-00000060 : Bluetooth Impersonation Attacks (BIAS) Vulnerability in Bluetooth BR/EDR

Flags: Bluetooth

CVSS Severity: Medium

CVSS String: [CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:L/I:L/A:N/E:F/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:L/I:L/A:N/E:F/RL:O/RC:C)

## Description

- It is possible for an attacking device spoofing the address of a previously bonded remote device to successfully complete the authentication procedure with some paired/bonded devices while not possessing the link key. This may permit an attacker to negotiate a reduced encryption key strength with a device that is still vulnerable to the Key Negotiation of Bluetooth (KNOB) attack disclosed in 2019. If the encryption key length reduction is successful, an attacker may be able to brute force the encryption key and spoof the remote paired device. If the encryption key length reduction is unsuccessful, the attacker will not be able to establish an encrypted link but may still appear authenticated to the host.

- For more information, see the following links:

  - [VU#647177](https://www.kb.cert.org/vuls/id/647177/)

  - [CVE-2020-10135](https://nvd.nist.gov/vuln/detail/CVE-2020-10135)

### Fix/Workaround

- Fixed in Bluetooth Smart Ready Software 1.3.0 and above, released 25 October, 2019. See the release notes for more details.

- Fixed in iWRAP 5.8.0 and iWRAP 6.3.0, released 9 October, 2019. See the release notes for more details.
