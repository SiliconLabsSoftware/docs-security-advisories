### Fix/Workaround

- EFR32 Customers – The Bluetooth LE SDK is not affected by the SweynTooth batch 2 vulnerabilities.

- BLE112/BLED112/BLE113/BLE121 customers – The BT Smart Software and SDK versions 1.8.0 and prior are affected by one or more SweynTooth vulnerabilities. BT Smart Software and SDK version 1.9.0, contains fixes for the issues. All affected customers are recommended to upgrade to 1.9.0 or later.

- BT121 Customers – This SDK is not affected by the Sweyntooth batch 2 vulnerabilities.
