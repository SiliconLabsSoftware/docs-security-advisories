| RS14100 Wi-Fi Secure SoCs and Modules | All supported | Not affected |

Note:
1. Test conditions: WFX firmware 3.4.1 with FMAC driver 2.4.0 
2. Test conditions: WFX firmware 3.4.1 with FMAC driver 2.4.0, and Gecko OS 4.2

## Description

- The vulnerability named ‘kr00k’ is an exploit discovered on Broadcom Wi-Fi client devices. The description of this vulnerability can be found here: [https://eset.com/int/kr00k/](https://eset.com/int/kr00k/)

- Reference: [CVE-2019-15126](https://nvd.nist.gov/vuln/detail/CVE-2019-15126)

### Fix/Workaround

- None required.
