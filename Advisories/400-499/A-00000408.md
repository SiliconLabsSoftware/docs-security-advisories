### Source Product Impact Details

- No Silicon Labs products are impacted by this vulnerability.

## Description

- A flaw in Java versions 15 through 18, inclusive, allows ECDSA signatures to be bypassed.

- No Silicon Labs products use any of the impacted versions of Java.

- A detailed description of the flaw is found in this [blogpost](https://neilmadden.blog/2022/04/19/psychic-signatures-in-java/).

- The following CVE, [CVE-2022-21449](https://nvd.nist.gov/vuln/detail/CVE-2022-21449), has been published regarding this issue.

### Fix/Workaround

- No fix or workaround is required since no Silicon Labs products are impacted by this vulnerability.
