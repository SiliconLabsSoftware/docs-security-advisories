# Silicon Labs Security Advisory A-00000480 : Security advisory for Gecko SDK TrustZone Implementation – unvalidated input leads to secure memory access from non-secure space

Flags: Security

CVSS Severity: High

CVSS Base Score: 9.0, Critical

CVSS Temporal Score: 8.6, High

CVSS String: [CVSS:3.1/AV:L/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:N/E:H/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:L/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:N/E:H/RL:O/RC:C)

### Source Product Impact Details

- EFx32xG2x SoCs and associated modules using TrustZone with the following pre-condition:
    - The ‘PSA Attestation Service for TrustZone Secure Key Library’ software component is installed. This component is not installed by default.

## CVE ID(s)

- [CVE-2023-4020](https://nvd.nist.gov/vuln/detail/CVE-2023-4020)[1] has been reserved for this vulnerability.

## Description

- An unvalidated input in a library function responsible for communicating between secure and non-secure memory allows reading/writing of memory in the secure region of memory from the non-secure region of memory.

- This issue is tracked in the Gecko Platform release notes, 4.4.0, as bug id# 1184675. The Gecko Platform release notes are available at the following link: [release notes](https://www.silabs.com/developers/gecko-software-development-kit)[2].

### Fix/Workaround

- Affected users should update to GSDK 4.4.0 or later. Instructions for downloading/updating the GSDK can be found in the Simplicity Studio Users Guide here: [Simplicity Studio User's Guide](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) [3].
