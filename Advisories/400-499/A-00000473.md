# Silicon Labs Security Advisory A-00000473 : Uninitialized local variable in Gecko Bootloader can cause data leakage from Secure stack

Flags: Security

CVSS Severity: Low

CVSS Base Score: 3.8, Low

CVSS Temporal Score: 3.4, Low

CVSS String: CVSS:3.1/AV:L/AC:L/PR:L/UI:N/S:C/C:L/I:N/A:N/E:P/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Gecko Bootloader | 2.3.0 and earlier | GSDK | 4.3.0 and earlier | [CVE-2023-3488](https://nvd.nist.gov/vuln/detail/CVE-2023-3488) |

### Source Product Impact Details

- EFx32xG2x SoCs and modules running a TrustZone-aware application with Gecko Bootloader from GSDK 4.3.0 or earlier may be impacted

## Description

- Gecko Bootloader can be used to upgrade the SE firmware, bootloader, or application using GBL files, delivered over the air or over the wire. If the application has a GBL file staged in memory, it can call bootloader_parseImageInfo() to have the Gecko Bootloader read out the Application Info from the GBL file.

- A malformed GBL file can be created that can cause the Gecko Bootloader to leak old information from the bootloader stack.

- In the case of a TrustZone-aware implementation, the Gecko Bootloader uses the Secure stack, meaning that this vulnerability could be used to leak old data from the Secure stack into a Non-Secure application.

- [CVE-2023-3488](https://nvd.nist.gov/vuln/detail/CVE-2023-3488) [1] has been reserved for this issue.

- This vulnerability is associated with bug ID #1161217 in the GSDK 4.3.1 release notes [2].

### Fix/Workaround

- Affected users should update to GSDK 4.3.1 or later. Instructions for downloading/updating the GSDK [3] and for upgrading a project to use a new GSDK version [4] can be found in the Simplicity Studio Users Guide.

- The patch can be applied directly by adding the following lines to the beginning of the parse_parseApplicationInfo() function of the impacted bootloader. This function can be found in the current GSDK in platform/bootloader/parser/gbl/btl_gbl_parser.c [5]:

        if (parserContext->lengthOfTag != sizeof(ApplicationData_t)) {
            return BOOTLOADER_ERROR_PARSER_UNEXPECTED;
        }
