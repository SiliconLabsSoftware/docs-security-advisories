# Silicon Labs Security Advisory A-00000470 : Security advisory for Wi-Fi protocol ‘Framing Frames’ vulnerabilities

Flags: Wi-Fi

CVSS Severity: Medium

CVSS Base Score: Varies

CVSS Temporal Score: Varies

CVSS String: Varies

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| - | - | - | - | - |

### Source Product Impact Details

- All Wi-Fi-capable SoCs and associated modules including RS9116, SiWx917, and WF200 may be impacted.

## Description

- The following report [https://www.usenix.org/system/files/sec23summer_355-schepers-prepub.pdf](https://www.usenix.org/system/files/sec23summer_355-schepers-prepub.pdf) discloses several vulnerabilities in the Wi-Fi protocol known as ‘Framing Frames’. ### Fix/Workaround

- No fix or workaround is provided at this time. As a member of the Wi-Fi alliance, Silicon Labs continues to contribute to and monitor the Wi-Fi specification. Any changes in the specification to address these vulnerabilities will be implemented in our active products.
