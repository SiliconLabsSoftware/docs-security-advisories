# Silicon Labs Security Advisory A-00000419 : Zigbee end nodes accept leave requests from nodes other than the parent resulting in a Denial of Service

Flags: Zigbee

CVSS Severity: Medium

CVSS Base Score: 5.7, Medium

CVSS Temporal Score: 5.1, Medium

CVSS String: CVSS:3.1/AV:A/AC:L/PR:L/UI:N/S:U/C:N/I:N/A:H/E:P/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| EmberZNet | 7.1.0 and earlier | GSDK | 4.1.0 and earlier | - |

### Source Product Impact Details

- EM35x and EFR32 Zigbee SoC’s and modules running EmberZNet 7.1.0 or earlier may be impacted

## Description

- When a Zigbee end node receives a “Leave” command from a node other than its parent, the command should be ignored. Refer to section 3.6.1.10.3.1.3 of the [Zigbee Specification](https://zigbeealliance.org/wp-content/uploads/2019/11/docs-05-3474-21-0csg-zigbee-specification.pdf) [1] for more details on the expected behavior.

- On EmberZNet 7.1.0 and earlier, end nodes will accept “Leave” commands from nodes other than the parent if the command is routed through the parent.

### Fix/Workaround

- Affected users should upgrade to EmberZNet 7.1.1 (distributed with GSDK 4.1.1) or later. 
    1. In Simplicity Studio’s Help menu, select the ‘Update Software’ menu item to open the Installation Manager 
    2. Click the ‘Manage installed packages’ button 
    3. Select the ‘SDKs’ tab and find the ‘Gecko SDK – 32-bit and Wireless MCUs’ section 
    4. If there are not currently any Installations, click the ‘Install New’ button. If there is an SDK already installed, click on the ‘...’ button next to its version number 
    5. Click ‘Change Version’
    6. In the ‘Versions:’ dropdown menu, select the desired version
    7. Click ‘FINISH’

- Systems that are sensitive to localized denial-of-service attacks such as this one can implement a heartbeat or other network health checks to detect these types of conditions and respond accordingly based on the application use case to promote a safe and secure system state. Examples of such health checks are given in [Reference](https://www.sciencedirect.com/science/article/pii/S187705091731027X) [2] below.
