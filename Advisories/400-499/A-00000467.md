# Silicon Labs Security Advisory A-00000467 : Security advisory for secure engine firmware using uninitialized IV for encrypting data in internal flash

Flags: Security

CVSS Severity: Low

CVSS Base Score: 3.1, Low

CVSS Temporal Score: 2.7, Low

CVSS String: [CVSS:3.1/AV:P/AC:H/PR:N/UI:N/S:U/C:L/I:L/A:N/E:U/RL:O/RC:X](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:P/AC:H/PR:N/UI:N/S:U/C:L/I:L/A:N/E:U/RL:O/RC:X)

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| SE Firmware | 2.0.1 through 2.0.0 | - | - | - |

### Source Product Impact Details

- Series 2 SoCs and associated modules with SE firmware version 2.0.0 through 2.2.1

## Description

- The initialization vector (IV) used by the secure engine (SE) for encrypting data stored in the SE flash memory is uninitialized. A re-used IV with the same encryption key can lead to leaking bits of the encryption key. An attacker cannot read the contents of the SE flash without destroying the device. Since the encryption key is unique per device, no feasible exploit is known.

- The IV used will be the 12 bytes of data at the top of the stack at the time. The IV will not likely be zero.

### Fix/Workaround

- Affected users should upgrade to SE firmware 2.2.2 or later, delivered as part of Gecko SDK 4.3.0, by doing the following:
    1. In Simplicity Studio’s Help menu, select the ‘Update Software’ menu item to open the Installation Manager
    2. Click the ‘Manage installed packages’ button
    3. Select the ‘SDKs’ tab and find the ‘Gecko SDK –32-bit and Wireless MCUs’ section
    4. If there are not currently any Installations, click the ‘Install New’ button. If there is an SDK already installed, click on the ‘...’ button next to its version number
    5. Click ‘Change Version’
    6. In the ‘Versions:’dropdown menu, select the desired version
    7. Click ‘FINISH’
    8. In the Launcher view of Simplicity Studio, select the adapter for your product and click on the ‘update to 2.2.2’ (or later)
