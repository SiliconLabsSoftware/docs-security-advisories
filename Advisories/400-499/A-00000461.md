# Silicon Labs Security Advisory A-00000461 : Security Advisory for Bluetooth LE invalid ‘prepare write request’ leads to Denial of Service

Flags: Bluetooth

CVSS Severity: Medium

CVSS Base Score: 6.5, Medium

CVSS Temporal Score: 6.2, Medium

CVSS String: CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H/E:H/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Bluetooth LE SDK | 5.1.0 and earlier | GSDK | 4.2.1 and earlier | [CVE-2023-0775](https://nvd.nist.gov/vuln/detail/CVE-2023-0775) |
| Bluetooth Mesh SDK | 3.0.4 and earlier | GSDK | 4.1.4 and earlier | [CVE-2023-0775](https://nvd.nist.gov/vuln/detail/CVE-2023-0775) |

### Source Product Impact Details

- EFR32-based Bluetooth LE capable SoCs and associated modules such as EFR32BGxxx and EFR32MGxxx running Bluetooth SDK 5.1.0 and earlier which is delivered as part of Gecko SDK 4.2.1 and earlier.

- EFR32-based Bluetooth Mesh capable SoCs and associated modules EFR32BGxxx and EFR32MGxxx running Bluetooth Mesh SDK 3.0.4 and earlier which is delivered as part of Gecko SDK 4.1.4 and earlier and which allow access to Bluetooth LE GATT characteristics through a Bluetooth LE connection.

## Description

- An invalid ‘prepare write request’ command can cause the stack to run out of memory and fail to be able to handle subsequent connection requests, resulting in a denial-of-service.

- The following CVE has been reserved for this vulnerability [CVE-2023-0775](https://nvd.nist.gov/vuln/detail/CVE-2023-0775).

- Release notes for the associated version fix can be referenced at [https://www.silabs.com/documents/public/release-notes/bt-software-release-notes-5.1.1.0.pdf](https://www.silabs.com/documents/public/release-notes/bt-software-release-notes-5.1.1.0.pdf) and can be found using the information in the table below:

| Bug ID # | Description | Impacted Versions | Impacted Component | Recovery Mechanism | Requires Pairing/Bonding |
| --- | --- | --- | --- | --- | --- |
| 1080356 | Invalid ‘prepare write request’ command causes a crash | Bluetooth SDK 5.1.0 and earlier, Bluetooth Mesh SDK 3.0.4 and earlier | Bluetooth stack | A reset is required to recover | No | 

### Fix/Workaround

- Affected users should upgrade to Bluetooth SDK 5.1.1 and/or Bluetooth Mesh SDK 4.2.0 or later, both of which are delivered as part of Gecko SDK 4.2.2 or later. This patch can be installed by performing the following steps: 
  1. In Simplicity Studio’s Help menu, select the ‘Update Software’ menu item to open the installation Manager.
  2. Click the ‘Manage installed packages’ button.
  3. Select the ‘SDKs’ tab and find the ‘Gecko SDK 32-bit and Wireless MCUs’ section.
  4. If there are not currently any Installations, click the ‘Install New’ button. If there is an SDK already installed, click on the ‘...’ button next to its version number.
  5. Click ‘Change Version’.
  6. In the ‘Versions:’ dropdown menu, select the desired version.
  7. Click ‘FINISH’.
