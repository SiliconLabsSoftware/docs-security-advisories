# Silicon Labs Security Advisory A-00000469 : Bluetooth LE Vulnerability – segmented prepare write response packet may lead to out-of-bounds memory access

Flags: Bluetooth

CVSS Severity: Medium

CVSS Base Score: 5.9, Medium

CVSS Temporal Score: 5.2, Medium

CVSS String: CVSS:3.1/AV:A/AC:H/PR:N/UI:N/S:U/C:N/I:L/A:H/E:U/RL:O/RC:C

## Description

- Forcing the Bluetooth stack to send a segmented ‘prepare write response’ packet may lead to an out-of- bounds memory access.

- The following CVE has been reserved for this issue - [https://nvd.nist.gov/vuln/detail/CVE-2023-3024](https://nvd.nist.gov/vuln/detail/CVE-2023-3024).

- This issue can be found in the release notes under bug id #1129475. Links to the release notes can be found at [https://www.silabs.com/developers/gecko-software-development-kit](https://www.silabs.com/developers/gecko-software-development-kit).

### Fix/Workaround

- Affected Bluetooth LE users using Bluetooth SDK versions 5.1.0 through 5.1.1, delivered as part of Gecko SDK 4.2.0 through 4.2.2 should upgrade to Bluetooth SDK version 5.1.2 or later, delivered as part of Gecko SDK 4.2.3 or later by following the instructions below:

- Affected Bluetooth LE users using Bluetooth SDK versions 4.2.2 and earlier, delivered as part of Gecko SDK 4.1.4 and earlier should upgrade to Bluetooth SDK 4.2.3 or later which is delivered as part of Gecko SDK version 4.1.5 or later by following the instructions below:
    1. In Simplicity Studio’s Help menu, select the ‘Update Software’ menu item to open the Installation Manager
    2. Click the ‘Manage installed packages’ button
    3. Select the ‘SDKs’ tab and find the ‘Gecko SDK –32-bit and Wireless MCUs’ section
    4. If there are not currently any Installations, click the ‘Install New’ button. If there is an SDK already installed, click on the ‘...’ button next to its version number
    5. Click ‘Change Version’
    6. In the ‘Versions: ’dropdown menu, select the desired version
    7. Click ‘FINISH’
    8. Select the new SDK in your project’s .slcp “Overview” tab, by clicking “Change Target/SDK/Generators”.
    9. Clean and re-build your project
