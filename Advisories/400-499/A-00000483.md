### Source Product Impact Details

- Bluetooth Classic-capable SoCs and associated modules including BT121, BT122, RS9113 and RS9116 may be impacted.

## Description

- A vulnerability in the Bluetooth protocol may allow an attacker to perform an encryption key downgrade attack, resulting in an encryption key weak enough to be brute-forced, allowing the attacker to decrypt all sessions using this key.

- The following CVE has been reserved for this vulnerability [CVE-2023-24043](https://nvd.nist.gov/vuln/detail/CVE-2023-24043).

### Fix/Workaround

- The best mitigation for this vulnerability is to require the strongest encryption key, 128 bits, as a minimum.
    - RS9113 and RS9116 based products currently do not have a mitigation for this vulnerability.
    - BT122 customers please see cmd_sm_set_minimum_key_size in section 3.16.1.14 of BT122 Dual Mode API Reference [1].

    - BT121 BT122 customers please see cmd_sm_set_minimum_key_size in section 3.16.1.12 of Bluetooth Dual Mode API Reference Manual [2].

## Certification Impact

- There is no impact to Bluetooth qualification due to this mitigation.
