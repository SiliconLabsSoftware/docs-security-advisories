# Silicon Labs Security Advisory A-00000477 : Z-Wave S0 Decryption Vulnerability in End Devices

Flags: Z-Wave

CVSS Severity: High

CVSS Base Score: 8.8, High

CVSS Temporal Score: 7.9, High

CVSS String: [CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H/E:P/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H/E:P/RL:O/RC:C)

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Z-Wave SDK | 7.19.2 and earlier | GSDK | 4.2.2 and earlier | [CVE-2023-51395](https://nvd.nist.gov/vuln/detail/CVE-2023-51395), [CVE-2023-0972](https://nvd.nist.gov/vuln/detail/CVE-2023-0972) |

### Source Product Impact Details

- Silicon Labs Z-wave end devices running Silicon Labs’ Z-Wave SDK 7.19.3 and earlier

## CVE ID(s)

- [CVE-2023-51395](https://nvd.nist.gov/vuln/detail/CVE-2023-51395) [1] is reserved for this vulnerability

## Description

- A buffer overrun in S0 decryption previously disclosed in [CVE-2023-0972](https://nvd.nist.gov/vuln/detail/CVE-2023-0972) [2] has been subsequently discovered by Silicon Labs developers in end device code
- This vulnerability may allow remote code execution on 700 and 800 series end devices whether S0 is enabled or disabled
- Remote code execution due to this exploit is not possible on 500 series devices under default configuration
- Knowledge of the network key is not required to exploit this vulnerability

### Fix/Workaround

- The recommended mitigation is to update to Z-Wave SDK 7.21.0 (GSDK 4.4.0) or later. However, the mitigation has additionally been backported to the mitigated branches appearing in the following table:

| Branch | Mitigated Versions | Bug ID # | Release Notes |
| --- | --- | --- | --- |
| 7.20.x | 7.20.0 (GSDK 4.3.0) or later | 1112282 | Z-Wave SDK 7.20.0 Release Notes [3] |
| 7.19.x | 7.19.3 (GSDK 4.2.3) or later | 1112282 | Z-Wave SDK 7.19.3 Release Notes [4] |
| 7.18.x | 7.18.8 (GSDK 4.1.6) or later | 1112282 | Z-Wave SDK 7.18.8 Release Notes [5] |
| 7.17.x | 7.17.5 (On-demand) | - | On-demand |

- To obtain the mitigation for version 7.17.x - contact Silicon Labs support [6]
- For all branches for which no patch is backported, you may upgrade to the next closest version available
- Instructions for downloading/updating the GSDK [7] and for upgrading a project to use a new GSDK version [8] can be found in the Simplicity Studio Users Guide
