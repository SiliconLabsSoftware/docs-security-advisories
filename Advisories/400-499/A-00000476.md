# Silicon Labs Security Advisory A-00000476 : Secure Boot Bypass via GBL Parser Vulnerability

Flags: Security

CVSS Severity: High

CVSS Base Score: 9.8, Critical

CVSS Temporal Score: 8.5, High

CVSS String: CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H/E:P/RL:O/RC:R

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Gecko Bootloader | 2.3.0 and earlier | GSDK | 4.3.0 and earlier | [CVE-2023-4041](https://nvd.nist.gov/vuln/detail/CVE-2023-4041) |

### Source Product Impact Details

- All Silicon Labs EFx32x modules and associated SoCs running “Standalone” or “Application” Gecko Bootloaders prior to GSDK 4.3.1 are affected
- GSDK 4.3.1 and later, and the “Mitigated Versions” appearing in Table 1 - Mitigated Branches are unaffected
- Only Second Stage Bootloaders (SSB) are affected by this vulnerability

## Description

- This vulnerability is tracked by [CVE-2023-4041](https://nvd.nist.gov/vuln/detail/CVE-2023-4041)
- Exploiting this vulnerability requires a malicious GBL to be uploaded to the device
- During firmware updates, a bug in the SSB update file (GBL) parser may allow an attacker to bypass application signature checks
- This vulnerability may allow an attacker gain persistent unsigned application code execution regardless of Secure Boot status
- The First Stage Bootloader’s (FSB) signature check on the SSB in RTSL devices is unaffected, however modification of the SSB is not required in order to gain persistent code execution due to this vulnerability
- Enabling GBL encryption hardens against, but does not prevent this vulnerability

### Fix/Workaround

- The recommended mitigation is to update to GSDK 4.3.1 or later. However, the mitigation for this vulnerability has been backported to the branches appearing in the following table for the “Mitigated Versions” Table 1 - Mitigated Branches

| Branch | Mitigated Versions | Bug ID # | Release Notes |
| --- | --- | --- | --- |
| GSDK 2.7.x | GSDK 2.7.12 or later | 1179641 | Gecko Platform 2.7.12.0 release notes |
| GSDK 3.2.x | GSDK 3.2.8 or later | 1179641 | Gecko Platform 3.2.8.0 release notes |
| GSDK 4.1.x | GSDK 4.1.6 or later | 1179641 | Gecko Platform 4.1.6.0 release notes |
| GSDK 4.2.x | GSDK 4.2.4 or later | 1179641 | Gecko Platform 4.2.4.0 release notes |
| GSDK 4.3.x | GSDK 4.3.1 or later | 1161217 | Gecko Platform 4.3.1.0 release notes |

- For all branches for which no patch is backported, you may upgrade to the next closest version available
- Instructions for downloading/updating the GSDK [1] and for upgrading a project to use a new GSDK version [2] can be found in the Simplicity Studio Users Guide
- To harden against this vulnerability, GBL file encryption should be enabled
- Do not install GBLs from untrusted sources, and always use link encryption when sending GBLs over the air
