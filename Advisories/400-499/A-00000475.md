# Silicon Labs Security Advisory A-00000475 : Vulnerabilities in PSA Crypto included in GSDK before 4.2.0

Flags: Security

CVSS Severity: Medium

CVSS Base Score: 7.5, High

CVSS Temporal Score: 6.5, Medium

CVSS String: [CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N/E:U/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N/E:U/RL:O/RC:C)

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Mbed TLS | 3.0.x and earlier | GSDK | 4.1.x and earlier | [CVE-2021-45450](https://nvd.nist.gov/vuln/detail/CVE-2021-45450), [CVE-2021-45451](https://nvd.nist.gov/vuln/detail/CVE-2021-45451) |

### Source Product Impact Details

- EFx32x SoCs and associated modules using psa_cipher_generate_iv, psa_cipher_encrypt, or psa_aead_generate_nonce from Mbed TLS before version 3.1.0 may be affected.

- Software NOT using the above APIs is unaffected

- Consult the table below to determine potentially impacted components:

| Stack/Solution | GSDK Versions | Impact |
| --- | --- | --- |
| BLE | Impacted 4.0.x-4.1.x | psa_cipher_encrypt is used |
| Bluetooth Mesh SDK | 4.0.x-4.1.x | psa_cipher_encrypt is used |
| Ember ZNet | 4.1.x | PSA Crypto not used in stack previous to GSDK 4.1 |
| Connect | 4.1.x | PSA Crypto not used in stack previous to GSDK 4.1 |
| Thread | 4.0.x-4.1.x | psa_cipher_encrypt is used |
| Z-Wave | 4.1.x | Affected APIs are not used prior to GSDK 4.1 |
| Matter | none | None, PSA Crypto is not used |
| Wi-Fi | none | None, PSA Crypto is not used |
| Wi-Sun | none | None, Wi-Sun does not use any of the vulnerable APIs |
| RS91x | none | None, PSA Crypto is not used in RS91x |
| MicriumOS/Plat-MTL | 4.0.x-4.1.x | CLI Password Protection module uses affected APIs |

## Description

- In Mbed TLS 3.x before 3.1.0, certain APIs are vulnerable to policy bypass or oracle-based decryption due to output buffers being read back

- For more information, refer to the table below for the associated CVEs for these vulnerabilities

| CVE | Third Party Advisory |
| --- | --- |
| [CVE-2021-45450](https://nvd.nist.gov/vuln/detail/CVE-2021-45450) [1] | Mbed TLS 3.1.0 [3] |
| [CVE-2021-45451](https://nvd.nist.gov/vuln/detail/CVE-2021-45451) [2] | Mbed TLS 3.1.0 [3] |

### Fix/Workaround

- Impacted GSDK users should update to version 4.2.x or later

    1. Under Simplicity Studio 5, navigate to the Installation Manager by clicking: or by navigating to “Help” > “Update Software,”
    2. Under the Installation Manager, select “Manage Installed Packages” > “SDKs” and install Gecko SDK 4.2.0 or greater, then clean and rebuild your project

## Certification Impact

- Recertification may be required. Please contact to your protocol’s certification body to determine potential certification implications.
