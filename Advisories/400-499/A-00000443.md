# Silicon Labs Security Advisory A-00000443 : Some ZigBee Dynamic Multiprotocol references use Well Known key as APS key

Flags: Zigbee

CVSS Severity: Medium

CVSS Base Score: 6.1, Medium

CVSS Temporal Score: 5.3, Medium

CVSS String: CVSS:3.1/AV:A/AC:H/PR:L/UI:R/S:U/C:N/I:H/A:H/E:U/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| DMP Light reference design | - | GSDK | 4.1.1 and earlier | - |

### Source Product Impact Details

- Only ZigBee Dynamic Multiprotocol (DMP) devices modeled after Silicon Labs’s DMP Light reference design released with Gecko SDK 4.1.1 and earlier, that are using Centralized Joining Mode

- Only DMP references are affected, for example: the Z3Light reference is NOT affected by this vulnerability

- Devices not using Centralized Joining mode are NOT affected by this vulnerability

## Description

- Due to a bug in the DMP Light reference, the ZigBeeAlliance09 key may be selected as an APS key during the confirmation phase of APS key negotiation in Centralized Join mode.

- As a result of this defect, a malicious user already connected to the network, may be able to convince a joining device to use the Well-Known key in place of its APS key – potentially leading to that device’s network key being changed by fraudulent Trust Centers as well as loss of Application Sublayer privacy.

### Fix/Workaround

- Affected users should immediately upgrade to Geco SDK Version 4.1.2 or higher

    1. Navigate to the “Help > Update Software” context menu under Simplicity Studio, or click:
    2. Select Gecko SDK Version 4.1.2, or higher under the “SDKs” tab, and install
    3. Select the new SDK in your project’s .slcp “Overview” tab, by clicking “Change Target/SDK/Generators”
    4. Clean and re-build your project
