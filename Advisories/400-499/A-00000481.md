- Projects based on the micriumos_webmic reference program released in GSDK 4.3.1 and earlier are affected

## Description

[CVE-2023-25181](https://nvd.nist.gov/vuln/detail/CVE-2023-25181) – uC-HTTP Server buffer overflow vulnerability
- Request processing code in Micrium OS Network HTTP server had a heap-based buffer overflow vulnerability
- An attacker can send a specially crafted set of network packets to trigger this vulnerability, potentially gaining arbitrary code execution on the system 

[CVE-2023-27882](https://nvd.nist.gov/vuln/detail/CVE-2023-27882) - uC-HTTP Server form boundary heap-based buffer overflow vulnerability
- Boundary string parsing code in Micrium OS Network HTTP server included a heap overflow vulnerability
- An attacker can send a specially crafted network packet to trigger this vulnerability, potentially gaining arbitrary code execution on the system 

[CVE-2023-28379](https://nvd.nist.gov/vuln/detail/CVE-2023-28379) - uC-HTTP HTTP Server form boundary memory corruption vulnerability
- Request parsing code in Micrium OS Network HTTP server included a heap overflow vulnerability
- An attacker can send a specially crafted network packet to trigger this vulnerability, potentially gaining arbitrary code execution on the system 

[CVE-2023-28391](https://nvd.nist.gov/vuln/detail/CVE-2023-28391) – uC-HTTP Server memory corruption vulnerability
- Header parsing code in Micrium OS Network HTTP server included a memory corruption vulnerability
- An attacker can send a malicious network packet to potentially gain arbitrary code execution on the system 

[CVE-2023-31247](https://nvd.nist.gov/vuln/detail/CVE-2023-31247) – uC-HTTP HTTP Server Host header parsing memory corruption vulnerability
- Host header processing code in Micrium OS Network HTTP server included a memory corruption vulnerability
- An attacker can send a malicious network packet to trigger this vulnerability, potentially gaining arbitrary code execution on the system 

[CVE-2023-24585](https://nvd.nist.gov/vuln/detail/CVE-2023-24585) – uC-HTTP HTTP Server out-of-bounds write vulnerability
- Method parsing code in Micrium OS Network HTTP server allowed an out of bounds write
- An attacker can send a specially crafted network request to trigger this vulnerability

### Fix/Workaround

- Affected users should update Micrium OS Network 5.15.1 or higher (included in GSDK 4.3.2 or later)
- Instructions for [downloading/updating the GSDK](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-about-the-launcher/toolbar#install) and for [upgrading a project to use a new GSDK version](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) can be found in the Simplicity Studio Users Guide
