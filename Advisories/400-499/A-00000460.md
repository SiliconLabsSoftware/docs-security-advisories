# Silicon Labs Security Advisory A-00000460 : Simplicity Studio UI in versions 5.4.x through 5.6.3 display web proxy credentials in plaintext

Flags: Security

CVSS Severity: Medium

CVSS Base Score: 7.1, High

CVSS Temporal Score: 6.8, Medium

CVSS String: [CVSS:3.1/AV:L/AC:L/PR:L/UI:N/S:U/C:H/I:N/A:H/E:H/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:L/AC:L/PR:L/UI:N/S:U/C:H/I:N/A:H/E:H/RL:O/RC:C)

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Simplicity Studio | 5.6.3 through 5.4.0 | - | - | - |

### Source Product Impact Details

- Simplicity Studio Versions between 5.4.x and 5.6.3.x are affected
- Simplicity Studio 4 is NOT affected
- Users not configuring a web proxy through Simplicity are NOT affected
- Commandline tools are NOT affected

## Description

- A feature introduced in Simplicity Studio 5.4.0.0 allowed users to enter web proxy credentials under Simplicity in order to use a web proxy to check for software updates, in the course of developing this feature, debugging instrumentation was left in place that displays plaintext web proxy credentials within the Simplicity GUI
- While no known exploit exists in the wild, it is possible a malicious user with physical access to the Simplicity Studio UI could extract your proxy credentials
- The web proxy credentials also appear in exported logfiles in Simplicity Studio 5.4.x through 5.6.3, these are generated through the [Help] > [Report Bug] menu, please ensure you delete all files containing these credentials
- Credentials impacted are NOT related to your Silabs account, however if you have re-used the same credentials for your web proxy elsewhere it is STRONGLY RECOMMENDED to update all usernames and passwords potentially impacted

### Fix/Workaround

- Affected users should update Simplicity Studio to a version GREATER THAN OR EQUAL TO 5.6.4
    - Identify your version of Simplicity through “Help” => “About Simplicity Studio”
    - Within Simplicity Studio, navigate to “Help” => “Update Software” or click the “Install” button, then go to “Manage installed packages” and check “Product Updates” for the latest version of Simplicity Studio
- This vulnerability can be mitigated by clearing proxy credentials from Simplicity
    - Within Simplicity Studio, navigate to “Preferences” => “General” => “Network Connections” and ensure “Active Provider” is NOT set to “Manual”
