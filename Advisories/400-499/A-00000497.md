# Silicon Labs Security Advisory A-00000497 : Potential DoS due to bus-fault in Sub-Ghz Zigbee implementation

Flags: Zigbee

CVSS Severity: Medium

CVSS Base Score: 5.3, Medium

CVSS Temporal Score: 4.8, Medium

CVSS String: [CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:L/E:P/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:L/E:P/RL:O/RC:C)

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| EmberZNet | 7.3.x and earlier | GSDK | 4.3.x and earlier | [CVE-2023-51393](https://nvd.nist.gov/vuln/detail/CVE-2023-51393), [CVE-2023-51392](https://nvd.nist.gov/vuln/detail/CVE-2023-51392) |

### Source Product Impact Details

- EFR32+Si4468-based devices using EmberZNet in a dual-PHY configuration prior to version 7.4.0.0 (GSDK 4.4.0)

## CVE ID(s)

- This vulnerability is tracked by [CVE-2023-51393](https://nvd.nist.gov/vuln/detail/CVE-2023-51393) [1].

## Description

- In a high traffic environment, a Sub-G Zigbee network coordinator can be provoked to change duty cycle leading to an eventual bus-fault due to lack of resources.

- The device then resets and is unavailable until it reboots and rejoins the network.

### Fix/Workaround

- Affected users should upgrade to Gecko SDK 4.4.0, or later.
- Instructions for downloading/updating the GSDK [2] and for upgrading a project to use a new GSDK version [3] can be found in the Simplicity Studio Users Guide.
