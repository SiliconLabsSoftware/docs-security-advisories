### Source Product Impact Details

- Z-Ware 7.18.2 and earlier

- SimplicityStudio version 5.6.x and earlier

- Bluetooth CBAP/Bluetooth Mesh CBP

## Description

- OpenSSL recently disclosed a set of eight vulnerabilities here [https://www.openssl.org/news/secadv/20230207.txt](https://www.openssl.org/news/secadv/20230207.txt).

- Simplicity Studio may be impacted by the vulnerabilities mentioned above through its inclusion of ‘git’ which relies on OpenSSL.

- Z-Ware may be impacted by the vulnerabilities mentioned above through its reliance on the OpenSSL library.

- The Bluetooth and Bluetooth Mesh products may be impacted through their reliance on the OpenSSL console application that runs on the developers host machine. OpenSSL is used in this case for signing certificate signing requests (CSRs).

- The vulnerabilities are summarized in the following table: Type of

### Fix/Workaround

- Simplicity Studio users should update to version 5.7.0 by installing from the following link [https://www.silabs.com/developers/simplicity-studio](https://www.silabs.com/developers/simplicity-studio)

- Bluetooth CBAP and Bluetooth Mesh CBP customers should install the latest Python ‘cryptography’ since this library includes OpenSSL. To update this library, run the following command: 

        ‘pip install cryptography’

- Z-Ware is not under active maintenance, hence it is not planned to be patched.
