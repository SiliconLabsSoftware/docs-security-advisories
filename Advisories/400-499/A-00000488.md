# Silicon Labs Security Advisory A-00000488 : Z-Wave denial of service caused by stream of packets

Flags: Z-Wave

CVSS Severity: Medium

CVSS Base Score: 5.7, Medium

CVSS Temporal Score: 5.5, Medium

CVSS String: CVSS:3.1/AV:A/AC:L/PR:L/UI:N/S:U/C:N/I:N/A:H/E:H/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Z-Wave SDK | 7.20.x and earlier | GSDK | 4.3.x and earlier | [CVE-2023-5310](https://nvd.nist.gov/vuln/detail/CVE-2023-5310) |

### Source Product Impact Details

- All Z-Wave NCP controller and endpoint devices running Z-Wave SDK 7.20.x and earlier (GSDK 4.3.x and earlier).

## CVE ID(s)

- [CVE-2023-5310](https://nvd.nist.gov/vuln/detail/CVE-2023-5310) [1] is reserved for this issue.

## Description

- A Denial of Service (DoS) attack can be carried out on all Z-Wave NCP controller and endpoint devices by sending a stream of packets to the device. This attack can only be initiated by a device on the network.

### Fix/Workaround

- The vulnerability is addressed in GSDK 4.4.0 and later (Z-Wave SDK 7.21.0 and later) as Bug ID #1166462 in the GSDK release notes [2]. Customers are always recommended to upgrade to the latest SDK version.

- Instructions for updating to the latest GSDK can be found in the Simplicity Studio User’s Guide here: Simplicity Studio User’s Guide [3].
