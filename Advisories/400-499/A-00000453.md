## Description

- Receiving a ‘connection update request’ message from a peer device while the local device is in the process of closing the connection causes a memory leak which exhausts the memory used for servicing connections, thus making future connections impossible. A reset of the device immediately clears the error.

- The following CVE has been reserved for this vulnerability [CVE-2023-2683](https://nvd.nist.gov/vuln/detail/CVE-2023-2683).

- This issue can be found in the ‘fixed issues’ section of the Bluetooth SDK release notes ([https://www.silabs.com/documents/public/release-notes/bt-software-release-notes-6.0.0.0.pdf](https://www.silabs.com/documents/public/release-notes/bt-software-release-notes-6.0.0.0.pdf)) under ID# 1084247.

### Fix/Workaround

- Affected Bluetooth LE users should upgrade to Bluetooth SDK version 6.0.0 or later which is delivered as part of Gecko SDK version 4.3.0 or later by following the instructions below:

- Affected Bluetooth Mesh users should upgrade to Bluetooth Mesh SDK version 5.0.0 or later which is delivered as part of Gecko SDK version 4.3.0 or later by following the instructions below: 
    1. In Simplicity Studio’s Help menu, select the ‘Update Software’ menu item to open the Installation Manager 
    2. Click the ‘Manage installed packages’ button 
    3. Select the ‘SDKs’ tab and find the ‘Gecko SDK –32-bit and Wireless MCUs’ section 
    4. If there are not currently any Installations, click the ‘Install New’ button. If there is an SDK already installed, click on the ‘...’ button next to its version number 
    5. Click ‘Change Version’ 
    6. In the ‘Versions: ’dropdown menu, select the desired version 
    7. Click ‘FINISH’ 
    8. Select the new SDK in your project’s .slcp “Overview” tab, by clicking “Change Target/SDK/Generators”. 
    9. Clean and re-build your project
