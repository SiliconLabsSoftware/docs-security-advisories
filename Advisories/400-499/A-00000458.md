# Silicon Labs Security Advisory A-00000458 : Wi-SUN SDK and Linux Border Router fail to enforce MAC level security

Flags: Wi-SUN

CVSS Severity: High

CVSS Base Score: 8.2, High

CVSS Temporal Score: 7.4, High

CVSS String: CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:L/A:H/E:P/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Wi-SUN SDK | 1.5.0 and earlier | GSDK | 4.2.1 and earlier | [CVE-2023-1261](https://nvd.nist.gov/vuln/detail/CVE-2023-1261) |
| Wi-SUN Linux Border Router | 1.5.2 and earlier | - | - | [CVE-2023-1262](https://nvd.nist.gov/vuln/detail/CVE-2023-1262) |

### Source Product Impact Details

- EFR32 SoCs and devices running the Wi-SUN SDK 1.5.0 and earlier may be impacted

- Solutions based on the Wi-SUN Linux Border Router 1.5.2 and earlier may be impacted

## Description

- The Wi-SUN specification requires that IEEE 802.15.4 security level 6 [1] is used for all frames with security enabled. Security level 6 involves encryption and a 64-bit message integrity code (MIC) for confidentiality, integrity, and authenticity of frames in the MAC layer.

- The software in the Impacted Products section above do not properly enforce level 6 MAC layer security on incoming messages. Due to this, an attacker can spoof a valid node and send malicious message to disrupt the network.

- Note that an attacker cannot use this vulnerability directly to join the network or gain any network or link keys, and there is therefore no impact on the confidentiality of frames transmitted between valid nodes.

- This issue is being tracked in CVE-2023-1261 (Wi-SUN SDK) and CVE-2023-1262 (Wi-SUN Linux Border Router).

### Fix/Workaround

- Affected Wi-SUN Linux Border Router users should upgrade to 1.5.3 or later.
    - Instructions for installing the most recent version can be found on the public github repository. [2]

- Affected Wi-SUN SDK users should upgrade to 1.5.1 (distributed with GSDK 4.2.2) or later. 
    1. In Simplicity Studio’s Help menu, select the ‘Update Software’ menu item to open the Installation Manager
    2. Click the ‘Manage installed packages’ button
    3. Select the ‘SDKs’ tab and find the ‘Gecko SDK – 32-bit and Wireless MCUs’ section
    4. If there are not currently any Installations, click the ‘Install New’ button. If there is an SDK already
    installed, click on the ‘...’ button next to its version number
    5. Click ‘Change Version’
    6. In the ‘Versions:’ dropdown menu, select the desired version
    7. Click ‘FINISH’
