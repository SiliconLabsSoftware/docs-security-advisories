# Silicon Labs Security Advisory A-00000490 : Security advisory for Bluetooth LE invalid ‘prepare write request’ in SiWx91x may lead to denial of service

Flags: Bluetooth

CVSS Severity: Medium

CVSS Base Score: 6.5, Medium

CVSS Temporal Score: 6.2, Medium

CVSS String: CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H/E:H/RL:O/RC:C

| Product | Impacted Version | Main SDK | Impacted Version | CVE |

### Source Product Impact Details

- SiWx915/SiWx917-based NCPs and associated modules where the host maintains GATT records

## Description

- An invalid ‘prepare write request’ command can cause the stack to run out of memory and fail to be able to handle subsequent connection requests, resulting in a denial-of-service.

- In systems where the SiWx91x device maintains GATT records there is no impact.

- In systems where the GATT records are maintained by the host, a denial of service caused by a crash may occur if the application does not handle errors returned by API calls correctly.

- The following CVE has been reserved for this vulnerability [CVE-2023-0775](https://nvd.nist.gov/vuln/detail/CVE-2023-0775) [3].

### Fix/Workaround

- Application code can mitigate this vulnerability by validating the size of data received when calling <rsi_ble_on_gatt_prepare_write_event_t>, if the length of data received will not fit in the available space it should be discarded. Further information is available in:
    - rsi-ble-on-gatt-prepare-write-event-t [1]
    - rsi-ble-event-prepare-write-s [2]
