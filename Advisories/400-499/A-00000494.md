# Silicon Labs Security Advisory A-00000494 : Potential for a Bluetooth LE HCI buffer overflow

Flags: Bluetooth

CVSS Severity: Medium

CVSS Base Score: 7.5, High

CVSS Temporal Score: 6.3, Medium

CVSS String: [CVSS:3.1/AV:A/AC:H/PR:N/UI:N/S:U/C:H/I:H/A:H/E:U/RL:O/RC:R](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:A/AC:H/PR:N/UI:N/S:U/C:H/I:H/A:H/E:U/RL:O/RC:R)

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Bluetooth LE SDK | 6.x and earlier | GSDK | 4.3.x and earlier | [CVE-2023-6387](https://nvd.nist.gov/vuln/detail/CVE-2023-6387) |

### Source Product Impact Details

- Bluetooth LE host implementations based on the cpc_hci bridge sample application found in the Gecko SDK earlier than 4.4.0.

## CVE ID(s)

- [CVE-2023-6387](https://nvd.nist.gov/vuln/detail/CVE-2023-6387)[1] has been reserved for this issue

## Description

- Due to an incorrect length calculation, an overflow of the buffer used to store packets received from the radio co-processor (RCP) is possible. This impacts the host platform running Bluetooth LE HCI bridge. The RCP device is not impacted.

- The buffer overflow may result in a denial-of-service or remote code execution on the host platform. Actual impact will depend on the memory layout of the host system.

### Fix/Workaround

- Affected users should upgrade to Gecko SDK 4.4.0, or later. Instructions for downloading/updating the GSDK can be found in the Simplicity Studio Users Guide here Simplicity Studio User's Guide. [2]
