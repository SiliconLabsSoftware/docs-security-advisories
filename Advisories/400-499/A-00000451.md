# Silicon Labs Security Advisory A-00000451 : Informational: Bug in Ember ZNet causes “Trust Center requires install code for joining” policy to be lost after invoking “plugin network-creator-security open-with-key” command

Flags: Zigbee

CVSS Severity: Low

CVSS String: -

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| EmberZNet | 7.2.1 through 6.2.0 | GSDK | 4.2.1 through 3.2.0 | - |

### Source Product Impact Details

- EFR32 Zigbee SoCs and modules that meet all the following criteria may be impacted:

    - Running Ember ZNet version between 6.2.0 (distributed with GSDK version 3.2.0) and 7.2.1 (distributed with GSDK version 4.2.1), inclusive.
    - Using the “Trust Center requires install code for joining” policy to limit which devices can join the network.

## Description

- When the “Trust Center requires install code for joining” policy is selected, devices can only join the network if they have a unique key for joining. Due to a bug in EmberZNet, if the user invokes “plugin network-creator- security open-with-key” to add a device to the network, the “Trust Center requires install code for joining” policy will be lost. Note that this does NOT mean that devices with the well-known key can join the network; it only means that network creator commands are then allowed to add the well-known key.

- Note that “plugin network-creator-security open-network” should NOT be invoked when the “Trust Center requires install code for joining” policy is enabled. The “plugin network-creator-security open-network” command allows joining using the well-known key without the use of an install code.

- This bug is tracked in the EmberZNet 7.2.2 Release Notes under bug ID #1079388. The release notes can be found at [https://github.com/SiliconLabs/gecko_sdk/releases](https://github.com/SiliconLabs/gecko_sdk/releases).

- This issue has been given a Severity of “Low” due to the lack of an in-the-field exploit. As long as the correct commands are used during network configuration, there is no risk of exploit.

### Fix/Workaround

- Affected users should upgrade to the latest release of Ember ZNet included in Gecko SDK 4.2.2 or later
    - Through Simplicity Studio, select “Install,” then under the “SDK” tab, select Gecko SDK - 32-bit and Wireless MCUs version 4.2.2 or higher
    - Select the installed version of Gecko SDK in “Launcher” under “General Information / Preferred SDK”
    - Rebuild your projects or reflash demo software using the new SDK

- Devices running affected versions of Ember ZNet that use the “Trust Center requires install code for joining” policy should follow the steps below:
    - Invoke the “plugin network-creator-security set-joining-link-key” command to add the joining key to the network
    - Invoke the “network join” command to open the network to joining
