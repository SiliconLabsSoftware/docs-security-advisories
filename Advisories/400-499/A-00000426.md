### Fix/Workaround

- BT122 customers should update to SDK 1.2.0, or later, which can be downloaded from the software tab of the following [link](https://www.silabs.com/wireless/bluetooth/bluetooth-br-edr-modules/device.bt122). This update includes a feature to indicate a radio hardware failure which can be used by the application to reset the device.

- RS9116 customers should update to SDK 2.6.0 or later which mitigates all of the vulnerabilities listed in the first table above. Instructions for updating can be found at the following [link](https://docs.silabs.com/rs9116-wiseconnect/latest/wifibt-wc-release-notes/#updating-to-this-release).

- No fix is planned for the BT121 product at this time.

- The WT32I module has reached end-of-life status and will not be patched.

- No fixes are planned for the RS9113 family of products at this time.
