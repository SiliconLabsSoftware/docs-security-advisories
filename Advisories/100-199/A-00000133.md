# Silicon Labs Security Advisory A-00000133 : Denial of Service vulnerability on Zigbee end nodes during Secure Rejoin

Flags: Zigbee

CVSS Severity: Medium

CVSS Base Score: 6.5, Medium

CVSS Temporal Score: 5.9, Medium

CVSS String: CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H/E:P/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| EmberZNet | 6.7.6 and earlier | GSDK | 2.7.6 and earlier | - |
| EmberZNet | 6.8.0 | GSDK | 3.0.0 | - |

### Source Product Impact Details

- Bug ID # 488395

- Zigbee end nodes running EmberZNet versions 6.7.6 and earlier (GSDK 2.7.6 and earlier) and version 6.8.0 (GSDK 3.0.0)

## Description

- A Zigbee end node that requests a Secure Rejoin will accept a malicious unsecured rejoin response, preventing it from rejoining its assigned network, resulting in a Denial of Service.

### Fix/Workaround

- GSDK 2.7.x / EmberZNet versions 6.7.x – This issue was fixed in EmberZNet versions 6.7.7 and later which was first released in GSDK 2.7.7

- GSDK 3.x / EmberZNet version 6.8.x – This issue was fixed in EmberZNet versions 6.8.1 and later which was first released in GSDK 3.0.1

- Affected end nodes should be upgraded to avoid the issue.
