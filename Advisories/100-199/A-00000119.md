# Silicon Labs Security Advisory A-00000119 : Bluetooth LE AoX Position Spoofing Attack

Flags: Bluetooth

CVSS Severity: Medium

CVSS Base Score: 6.2

CVSS Temporal Score: 5.6

CVSS String: [CVSS:3.1/AV:L/AC:L/PR:N/UI:N/S:U/C:N/I:H/A:N/E:P/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:L/AC:L/PR:N/UI:N/S:U/C:N/I:H/A:N/E:P/RL:O/RC:C)


## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Bluetooth LE SDK | 3.3.1 and earlier | GSDK | 4.0.1 and earlier | - |

### Source Product Impact Details

- EFR32BG22-based modules and SoCs running Bluetooth® LE SDK 3.3.1 and older.

## Description

- An attacker can spoof the location of a legitimate tag to make it appear to be in a false location.

- This can be accomplished either by a third-party tag sending false data to overwrite the legitimate tag data or by the firmware on a legitimate tag being corrupted to send false data.

### Fix/Workaround

- Customers using angle reporting mode should update to Bluetooth SDK 3.3.2, which is included in Gecko SDK 4.0.2, or later. Instructions for updating are found below:
    1.   In Simplicity Studio’s help menu, click the Update Software meu item to open the Installation Manager
    dialog.
    2. In the Installation Manager dialog, click the Manage installed packages button.
    3. Select the SDKs tab, click the ‘...’ button, select the ‘Change Version’ menu item, then select ‘4.0.2’
    or higher from the pulldown list and click the ‘Finish’ button.
    4.   Click the Install New button under in the section titled ‘Gecko SDK – 32-bit and Wireless MCUs’.
- A mitigation for this vulnerability will be available for IQ reporting mode later this year.
