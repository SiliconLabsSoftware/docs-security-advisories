### Fix/Workaround

- For the RS9116 Issues marked “fixed” in the table above have been resolved in 2.4.0. For instructions on upgrading, please refer to the programming reference manual which can be found [here](https://www.silabs.com/documents/login/reference-manuals/rs9116w-wi-fi-at-command-programming-reference-manual.pdf).

- Fixes for the RS9113 will be issued in the fourth quarter of 2021. An updated advisory will be issued when the fixes are available.
