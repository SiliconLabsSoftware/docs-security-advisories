# Silicon Labs Security Advisory A-00000129 : NUMBER:JACK Security vulnerability in Micrium OS Network/GeckoOS allows hijacking or spoofing connections

Flags: Security

CVSS Severity: High

CVSS Base Score: 8.2, High

CVSS Temporal Score: 7.4, High

CVSS String: CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:H/A:L/E:P/RL:X/RC:R

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Micrium OS Network | 5.9.0 and earlier | - | - | [CVE-2020-27630](https://nvd.nist.gov/vuln/detail/CVE-2020-27630) |
| Micrium uC/TCP-IP | 3.6.0 and earlier | - | - | [CVE-2020-27630](https://nvd.nist.gov/vuln/detail/CVE-2020-27630) |
| Gecko OS | 4.2.5 and earlier | - | - | [CVE-2020-27630](https://nvd.nist.gov/vuln/detail/CVE-2020-27630) |

### Source Product Impact Details

- Micrium OS Network version 5.9.0 and earlier

- Micrium uC/TCP-IP 3.6.0 and earlier in Micrium uC/OS-II and uC/OS-III

- GeckoOS 4.2.5 and earlier

## Description

- The code that generates initial sequence numbers (ISNs) uses an insufficiently random source making it possible to hijack existing connections or spoof future connections

- The following vulnerability [CVE-2020-27630](https://nvd.nist.gov/vuln/detail/CVE-2020-27630) has been reserved for this issue

- The researcher has made a public blog post about this issue [here](https://www.forescout.com/company/blog/numberjack-forescout-research-labs-finds-nine-isn-generation-vulnerabilities-affecting-tcpip-stacks/)

### Fix/Workaround

- For Micrium OS Network, upgrade to version 5.10.0 or later using Simplicity Studio v5’s help -> Update Software -> Manage installed packages -> SDKs -> Micrium OS and click the Install button

- For uC/TCP-IP an issue has been logged here with the open source community and Silicon Labs has notified the custodians of Micrium uC/OS-II and uC/OS-III

- For GeckoOS, upgrade to version 4.2.6 or later using the Gecko OS Studio. Click the Tools icon, select the latest version and then click the download button
