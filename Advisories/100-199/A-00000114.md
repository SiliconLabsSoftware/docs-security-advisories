# Silicon Labs Security Advisory A-00000114 : Cumulative device resets can render EFR32xG21 or EFR32xG22 inoperable resulting in Denial of Service

Flags: Security

CVSS Severity: Medium

CVSS Base Score: 4.6 - Medium

CVSS Temporal Score: 4.0 - Medium

CVSS String: [CVSS:3.1/AV:P/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H/E:U/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:P/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H/E:U/RL:O/RC:C)

### Source Product Impact Details

- This issue is associated with PB #201027915, PB #201027921 and Software Advisory A-00000117
- The technical content of this Security Advisory is identical to Software Advisory A-00000117. The purpose of this Security Advisory is to communicate that the bug could potentially be used by a malicious actor to destroy the device, resulting in a denial of service.

## Product Impact

- EFR32xG21 and EFR32xG22 SoC’s and associated modules running (V)SE firmware 1.2.5 or earlier whose (V)SE firmware has been upgraded at least once.

## Description

- A device whose (V)SE firmware has been successfully upgraded at least once can become inoperable if the upgrade file is removed from flash after the upgrade and the device is subjected to a large cumulative number of resets or wake up from EM4 events. The exact number of reset cycles before failure varies due to process variations and operating temperature but would typically range between 50,000 and 200,000 cycles. It is imperative that this fix be applied to every device to avoid latent failures.

### Fix/Workaround

- This is fixed in (V)SE firmware 1.2.6 and later. Instructions for upgrading (V)SE firmware can be found in [UG266: Silicon Labs Gecko Bootloader User’s Guide](https://www.silabs.com/documents/public/user-guides/ug266-gecko-bootloader-user-guide.pdf) and [AN1222: Production Programming of Series 2 Devices](https://www.silabs.com/documents/public/application-notes/an1222-efr32xg2x-production-programming.pdf)
