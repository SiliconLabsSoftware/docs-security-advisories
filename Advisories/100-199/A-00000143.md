# Silicon Labs Security Advisory A-00000143 : Bluetooth LE Privacy allows device tracking

Flags: Bluetooth

CVSS Severity: Medium

CVSS Base Score: 6.5, Medium

CVSS Temporal Score: 6.2, Medium

CVSS String: [CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N/E:H/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N/E:H/RL:O/RC:C)

| RS9116 | Impacted | RS9116 based products are vulnerable since they can filter scan requests based on accept-lists |

## Description

- A Bluetooth LE device using LE privacy can be tracked through its responses to active scan requests.

- [CVE-2020-35473](https://nvd.nist.gov/vuln/detail/CVE-2020-35473) has been reserved for this issue.

- The researcher’s paper on this vulnerability is available [here](https://web.cse.ohio-state.edu/~lin.3021/file/CCS22a.pdf).

### Fix/Workaround

- A fix for the RS9116-based products will be delivered at a future date. Concerns about this issue can be addressed to silicon Labs’ support team at [https://www.silabs.com/support](https://www.silabs.com/support).

- No mitigations are required for the other products mentioned in this advisory since they are not impacted.
