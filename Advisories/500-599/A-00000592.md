
# Silicon Labs Security Advisory A-00000592 : Out-of-bounds read in Z-Wave NCP Serial API Handler

Flags: Z-Wave

CVSS Severity: Medium

CVSS String: [CVSS:4.0/AV:P/AC:L/AT:N/PR:N/UI:N/VC:H/VI:N/VA:N/SC:N/SI:N/SA:N](https://www.first.org/cvss/calculator/4.0#CVSS:4.0/AV:P/AC:L/AT:N/PR:N/UI:N/VC:H/VI:N/VA:N/SC:N/SI:N/SA:N)

## Product Impact
 * 700 and 800 series devices running impacted versions of the Z-Wave SDK are impacted
 * 500 series devices are NOT impacted

 
|Product|Impacted Version|Main SDK|Impacted Version|CVE|
|-------|----------------|--------|----------------|---|
|Z-Wave SDK|8.1.1 through 8.1.0|SiSDK|2026.6.1 through 2026.6.0|[CVE-2026-89410](https://nvd.nist.gov/vuln/detail/CVE-2026-89410)|
|Z-Wave SDK|8.0.2 and earlier|SiSDK|2025.12.3 and earlier|[CVE-2026-89410](https://nvd.nist.gov/vuln/detail/CVE-2026-89410)|
|Z-Wave SDK|7.21.x and earlier|GSDK|All released versions|[CVE-2026-89410](https://nvd.nist.gov/vuln/detail/CVE-2026-89410)|

## Description
 * An incorrect bounds check in the Z-Wave NCP Serial API command handler allows out-of-bounds reads.
 * For EFR32ZG23 devices, the vulnerable region ​includes the upgrade decryption key.
 * An attacker with physical access to the NCP UART can thereby read the decryption key and decrypt GBL upgrade files​


### Fix/Workaround

Instructions for [downloading/updating the SDK](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-about-the-launcher/toolbar#install) and for [upgrading a project](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) can be found in the Simplicity Studio Users Guide.

A fix for Z-Wave 700 Series devices is not available at this time.
