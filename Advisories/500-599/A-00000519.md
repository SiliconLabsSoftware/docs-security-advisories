## Description

- This notice is only intended to notify that an affected 3rd party component is included in Silicon Labs products. Please refer to the corresponding CVE for technical details.

    - This vulnerability is caused by a weakness in the Wi-Fi protocol specification.

### Fix/Workaround

- No fix is available for the affected products, since a fix would require having beacon protection enabled, which is deployed as part of Wi-Fi 7.

- The recommended workaround is to use different credentials across each Wi-Fi network, including networks on different bands. This would prevent the vulnerability from being exploited.
