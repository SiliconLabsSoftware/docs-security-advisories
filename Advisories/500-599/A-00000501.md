# Silicon Labs Security Advisory A-00000501 : Potential remote code execution due to heap-based buffer overflow in Micrium uC-HTTP

Flags: Security

CVSS Severity: High

CVSS Base Score: 9.0, Critical

CVSS Temporal Score: 8.2, High

CVSS String: [CVSS:3.1/AV:N/AC:H/PR:N/UI:N/S:C/C:H/I:H/A:H/E:P/RL:T/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:N/AC:H/PR:N/UI:N/S:C/C:H/I:H/A:H/E:P/RL:T/RC:C)

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Micrium OS Network | 5.15.1 and earlier | GSDK | 4.4.0 and earlier | [CVE-2023-45318](https://nvd.nist.gov/vuln/detail/CVE-2023-45318) |

### Source Product Impact Details

- Devices not using Micrium OS Network in server configuration are unaffected
- All devices using uC-HTTP server configuration from Micrium OS in GSDK 4.4.0 and earlier are affected
- Projects based on the micriumos_webmic reference program released in GSDK 4.4.0 and earlier are affected

## CVE ID(s)

- [CVE-2023-45318](https://nvd.nist.gov/vuln/detail/CVE-2023-45318) [1] is reserved for this vulnerability

## Description

- Protocol version processing code in Micrium OS Network HTTP server had a buffer overflow vulnerability
- An attacker can send a specially crafted set of network packets to exploit this vulnerability, potentially gaining arbitrary code execution on the system

### Fix/Workaround

- Affected users should update Micrium OS Network 5.15.2 or higher (included in GSDK 4.4.1 or later)
- Instructions for downloading/updating the GSDK [2] and for upgrading a project to use a new GSDK version [3] can be found in the Simplicity Studio Users Guide
