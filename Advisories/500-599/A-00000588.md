
# Silicon Labs Security Advisory A-00000588 : "Dis-connect" Vulnerability in Connect Stack

Flags: Connect, Flex

CVSS Severity: High

CVSS String: [CVSS:4.0/AV:A/AC:L/AT:N/PR:N/UI:N/VC:N/VI:H/VA:H/SC:N/SI:N/SA:N](https://www.first.org/cvss/calculator/4.0#CVSS:4.0/AV:A/AC:L/AT:N/PR:N/UI:N/VC:N/VI:H/VA:H/SC:N/SI:N/SA:N)

## Product Impact
|Product|Impacted Version|Main SDK|Impacted Version|CVE|
|-------|----------------|--------|----------------|---|
|Connect SDK|4.3.3 and earlier|SiSDK|2026.6.1 and earlier|[CVE-2026-66279](https://nvd.nist.gov/vuln/detail/CVE-2026-66279)|
|Flex SDK|3.7.7 and earlier|GSDK|4.5.0 and earlier|[CVE-2026-66279](https://nvd.nist.gov/vuln/detail/CVE-2026-66279)|

## Description
 * Due to a vulnerability in the Connect/Flex SDK MAC parser, messages with malformed MAC security field may be accepted without proper authentication
    * This allows an attacker to spoof messages on the network. This can potentially be used to change persistent network configurations or reset devices on the network
    * This does NOT allow an attacker to gain access to the network key or decrypt network traffic


### Fix/Workaround
 - Instructions for [downloading/updating the SDK](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-about-the-launcher/toolbar#install) and for [upgrading a project](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) can be found in the Simplicity Studio Users Guide.
