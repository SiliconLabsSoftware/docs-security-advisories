
# Silicon Labs Security Advisory A-00000590 : Zigbee Denial-of-Service Vulnerabilities

Flags: Zigbee

CVSS Severity: Low

CVSS String: [CVSS:4.0/AV:N/AC:L/AT:P/PR:L/UI:N/VC:N/VI:N/VA:H/SC:N/SI:N/SA:N](https://www.first.org/cvss/calculator/4.0#CVSS:4.0/AV:N/AC:L/AT:P/PR:L/UI:N/VC:N/VI:N/VA:L/SC:N/SI:N/SA:N)

## Product Impact
|Product|Impacted Version|Main SDK|Impacted Version|CVE|
|-------|----------------|--------|----------------|---|
|EmberZNet|9.1.1 and earlier|SiSDK|2026.6.1 and earlier|[CVE-2026-66281](https://nvd.nist.gov/vuln/detail/CVE-2026-66281), [CVE-2026-66282](https://nvd.nist.gov/vuln/detail/CVE-2026-66282), [CVE-2026-85080](https://nvd.nist.gov/vuln/detail/CVE-2026-85080)|

 

## CVE ID(s)
|CVE Number|Description|Required Cluster|
|----|----|----|
|[CVE-2026-66281](https://nvd.nist.gov/vuln/detail/CVE-2026-66281)|Authenticated DoS in Discover Attributes command|Manufacturer-specific Cluster|
|[CVE-2026-66282](https://nvd.nist.gov/vuln/detail/CVE-2026-66282)|Authenticated DoS in Publish Billing Period command|Price Cluster|
|[CVE-2026-85080](https://nvd.nist.gov/vuln/detail/CVE-2026-85080)|Authenticated DoS in Get Group Membership command|Group Cluster|

## Description
 * Three denial-of-service vulnerabilities have been identified in impacted versions of EmberZNet SDK.
 * In each case, the attacker must be on the network, and a specific cluster must be supported by the network (see the *CVE ID(s)* table for details).
 * Note that keep-alive measures such as watchdogs would detect these attacks and recover from them. 


### Fix/Workaround

Instructions for [downloading/updating the SDK](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-about-the-launcher/toolbar#install) and for [upgrading a project](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) can be found in the Simplicity Studio Users Guide.
