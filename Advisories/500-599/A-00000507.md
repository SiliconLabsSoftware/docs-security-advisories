# Silicon Labs Security Advisory A-00000507 : Micrium OS Network uC-HTTP server header parsing invalid pointer dereference vulnerability

Flags: Security

CVSS Severity: Medium

CVSS Base Score: 7.5, High

CVSS Temporal Score: 6.7, Medium

CVSS String: [CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H/E:P/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H/E:P/RL:O/RC:C)

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Micrium OS Network | 5.15.2 and earlier | GSDK | 4.4.1 and earlier | [CVE-2023-51391](https://nvd.nist.gov/vuln/detail/CVE-2023-51391) |

### Source Product Impact Details

- All devices using Network Suite HTTP Server from Micrium OS in GSDK 4.4.1 and earlier are affected.
- Devices not using Micrium OS Network Suite HTTP Server are unaffected.

## CVE ID(s)

- [CVE-2023-51391](https://nvd.nist.gov/vuln/detail/CVE-2023-51391) [1] is reserved for this vulnerability.

## Description

- A bug in HTTP parsing code causes a potential invalid pointer dereference when processing HTTP header values.
- An attacker can send an HTTP request containing specifically crafted key-value pairs to exploit this vulnerability, potentially crashing the device, causing a denial of service.

### Fix/Workaround

- Affected users should update Micrium OS Network 5.15.3 or higher (included in GSDK 4.4.2 or later).
- Instructions for downloading/updating the GSDK [2] and for upgrading a project to use a new GSDK version [3] can be found in the Simplicity Studio Users Guide.
