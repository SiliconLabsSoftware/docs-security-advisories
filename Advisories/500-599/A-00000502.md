## Description

Command

| ID | Class | Description | Recovery Method |
| --- | --- | --- | --- |
| 1 | New Node Registered | Malformed packets can be sent to add new fake nodes to the controller’s device table. Once the controller’s device table is filled, no additional nodes can be added, causing a temporary denial of service to new nodes joining the network. | To recover from this state, make both of the following app layer changes: 1. Prompt the controller to interview the end device and verify reported information. 2. Clean up the device table by removing devices that are not responsive or invalid |
| 2 | New Node Registered | Malformed packets can be sent to change the end device’s role in controller memory, preventing communication with the end device. | To recover from this state, make app layer changes to prompt the controller to interview the end device and verify reported information. |
| 3 | New Node Registered | Malformed packets can be sent to change the wakeup interval of end devices in controller memory, preventing communication with the end device. The end device behavior is not impacted by this change | To recover from this state, make app layer changes to prompt the controller to interview the end device and verify reported information. |
| 4 | New Node Registered | Malformed packets can be sent to change the device type in controller memory, preventing communication with the end device. The end device is not removed from the network | To recover from this state, make app layer changes to prompt the controller to interview the end device and verify reported information. |
| 5 | New Node Registered | Malformed packets can be sent to add a new fake node in controller memory or remove an existing node. | To recover from this state, make both of the following app layer changes: 1. Prompt the controller to interview the end device and verify reported information. 2. Clean up the device table by removing devices that are not responsive or invalid. |
| 6 | Version Command Class Get Association | Malformed packets can be sent to keep the controller busy with responding, which denies service to any other tasks that may be occurring. This denial of service can be used to repeatedly jam the controller. | The controller will recover without need for intervention after it finishes sending all response frames.  |
| 7 | Group Command List | As above. | As above. |
| 8 | Firmware MD Get Association | As above. | As above. |
| 9 | Group Command Info Get | As above. | As above. |
| 10 CVE-2023-6533 | Device Reset Locally | Malformed packets can be sent to the controller, causing the controller to assume that the end device has left the network. After this time frames sent by the end device will not be acknowledged by the controller | To recover from this state, make app layer changes to prompt the controller to interview the end device and verify reported information.  
| 11 | Firmware Update MD Request Get | Malformed packets can be sent to keep the controller busy with responding, which denies service to any other tasks that may be occurring. This denial of service can be used to repeatedly jam the controller. | The controller will recover without need for intervention after it finishes sending all response frames.  |
| 12 CVE-2020-10137 | Find Nodes in Range | Malformed packets can be sent to initiate the controller to poll the network for devices in range. If there is a large network, this will take time and lower the throughput of the network temporarily. | The controller will recover without need for intervention after it finishes polling for all devices in range. | 
| 13 | Power Test Node Set | Malformed packets can be sent to ask the The controller to perform long operations,     in rendering it unable to perform other tasks | controller will recover without need for tervention after it finishes all operations. |
| 14 CVE-2023-6640 | S2 Nonce Get | Malformed packets can be sent to crash the PC Controller tool 5.54.0 and earlier, delivered as part of Simplicity Studio. | No recovery method is available. The PC Controller tool must be restarted. |
| 15 | NIF | malformed packets can be sent to deny service between the controller and end device. Silicon Labs could not reproduce this attack. | This vulnerability could not be reproduced. |

### Fix/Workaround

| ID | Fix/Workaround Method |
| --- | --- |
| 1-5 | This vulnerability was mitigated in Z-Wave SDK versions 7.20.3, 7.21.2, and 7.22.0. Affected users should update to one of these versions or later. |
| 6-9, 11, 13 | A fix is not planned to address this vulnerability. |
| 12 | This vulnerability was mitigated in Z-Wave SDK 6.81.6 and later. Affected users should update to Z-Wave SDK 6.81.6 and later. Refer to the 500 Series User Guide [3] for more information on updating to a newer SDK version.
| 10, 14 | This vulnerability was mitigated in PC Controller 5.54.1, delivered alongside GSDK 4.2.0. Affected users should upgrade to PC Controller 5.54.1 and later. Instructions for installing the latest version of Simplicity Studio [4] can be found in the Simplicity Studio 5 User’s Guide. |
| 15 | Since this vulnerability was not reproduced, no official fix is planned. |
