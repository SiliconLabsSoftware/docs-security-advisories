## Description

- Specially crafted L2CAP packets targeting RS9116W devices using the RS9116W WiSeConnect SDK can cause the device to crash, leading to a Denial of Service (DoS). Recovery from such a state requires a hard reset.

### Fix/Workaround

- Currently there is no fix available for this issue.
