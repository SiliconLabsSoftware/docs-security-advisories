## CVE ID(s)

- [CVE-2024-10106](https://nvd.nist.gov/vuln/detail/CVE-2024-10106) is reserved for this issue

## Description

- The packet handoff plugin present in impacted versions of the EmberZnet SDK may cause a buffer overflow

- This buffer overflow triggers an assert, which causes a temporary denial of service

- The system will reset and recover from the denial of service due to a watchdog timeout

### Fix/Workaround

- Affected users should upgrade EmberZNet according to the table below.
- Instructions for [downloading/updating the SDK](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-about-the-launcher/toolbar%23install) and for [upgrading a project](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) can be found in the Simplicity Studio Users Guide.
