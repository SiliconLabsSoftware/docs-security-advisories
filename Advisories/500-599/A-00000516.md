# Silicon Labs Security Advisory A-00000516 : Possible failure to update the “Tamper Reset Cause” register when a level 4 tamper event occurs

Flags: Security

CVSS Severity: Low

CVSS Base Score: 2.0, Low

CVSS Temporal Score: 1.9, Low

CVSS String: [CVSS:3.1/AV:P/AC:H/PR:N/UI:N/S:U/C:N/I:L/A:N/E:P/RL:W/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:P/AC:H/PR:N/UI:N/S:U/C:N/I:L/A:N/E:P/RL:W/RC:C)

### Source Product Impact Details

- Series 2 HSE-SVH devices EFR32xG23B, EFR32xG24B, EFR32xG25B, and EFR32xG28B running SE Firmware 2.2.5 and earlier.
    - EFR32xG21B is not impacted.

## CVE ID(s)

- [CVE-2024-2502](https://nvd.nist.gov/vuln/detail/CVE-2024-2502) [1] is reserved for this issue.

## Description

- The TAMPERRSTCAUSE register may not be properly updated when a Level 4 tamper event (a tamper reset) occurs.

- The TAMPERRSTCAUSE register is only intended to be used by the application to determine if the last reset was caused by a tamper event. The application can be configured to block boot attempts after a certain number of consecutive tamper resets, which may not count the tamper resets as expected on SE firmware versions 2.2.5 and earlier.

### Fix/Workaround

- Upgrade to SE Firmware 2.2.6 or later to mitigate this issue on impacted Series 2 HSE-SVH devices.
    - For more information on how to perform a field upgrade of the SE Firmware, refer to Section 10 of AN1222: Production Programming of Series 2 Devices [2].

- Release notes for the SE Firmware can be found in the SDK under {SDK Location}\util\se_release\public.
