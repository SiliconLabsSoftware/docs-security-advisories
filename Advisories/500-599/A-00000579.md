## Description

- This report covers eleven Zigbee command handling vulnerabilities identified in the Zigbee Application Framework (ZAP). A malicious device admitted into the Zigbee network could crafted malformed packets that trigger these vulnerabilities.

- Most of the vulnerabilities above result in memory access faults or arithmetic faults that will lead to a reset. These vulnerabilities are marked with “DoS” in the Attack Nature column of the table above.

- [CVE-2026-47147](https://nvd.nist.gov/vuln/detail/CVE-2026-47147) covers an out-of-bounds read that could lead to RAM leakage over the air.

- [CVE-2026-47150](https://nvd.nist.gov/vuln/detail/CVE-2026-47150) covers an out-of-bounds write of one byte that results in a hard fault.

- [CVE-2026-47151](https://nvd.nist.gov/vuln/detail/CVE-2026-47151) covers an out-of-bounds write that could corrupt runtime variables.

### Fix/Workaround

- The following SDK release addresses the vulnerability. Customers are always recommended to upgrade to the latest SDK version.
