# Silicon Labs Security Advisory A-00000536 : A Zigbee network with heavy traffic causes a break in RCP communication with CPCd

Flags: Zigbee

CVSS Severity: Medium

CVSS Base Score: 5.9, Medium

CVSS String: [CVSS:4.0/AV:A/AC:L/AT:P/PR:L/UI:N/VC:N/VI:N/VA:H/SC:N/SI:N/SA:N](https://www.first.org/cvss/calculator/4.0#CVSS:4.0/AV:A/AC:L/AT:P/PR:L/UI:N/VC:N/VI:N/VA:H/SC:N/SI:N/SA:N)

## CVE ID(s)

- [CVE-2025-1221](https://nvd.nist.gov/vuln/detail/CVE-2025-1221) is reserved for this issue.

## Description

- A Zigbee Radio Co-Processor (RCP) was unable to send messages to the host system (CPCd) due to heavy Zigbee traffic, resulting in a Denial of Service (DoS) attack
    - Only hard reset will bring the device to normal operation

### Fix/Workaround

- To mitigate this vulnerability
    - Users of GSDK should upgrade to EmberZNet SDK 7.4.4, or later delivered as part of GSDK 4.4.4 or later
    - Users of Simplicity SDK should upgrade to
        - EmberZNet SDK 8.0.2, or later delivered as part of SiSDK V2024.6.2 or later
        - EmberZNet SDK v 8.1.0, or later delivered as part of SiSDK V2024.12.0 or later
- Instructions for updating the SiSDK and for upgrading a project to a new GSDK version can be found in the Simplicity Studio Users Guide

- Please refer to the following release notes for more information for the fix implemented
    - [EmberZNet 7.4.4](https://www.silabs.com/documents/public/release-notes/emberznet-release-notes-7.4.4.0.pdf)
    - [EmberZNet 8.0.2](https://www.silabs.com/documents/public/release-notes/emberznet-release-notes-8.0.2.0.pdf)
    - [EmberZNet 8.1.0](https://www.silabs.com/documents/public/release-notes/emberznet-release-notes-8.1.0.0.pdf)
