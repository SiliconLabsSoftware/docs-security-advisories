## CVE ID(s)

- [CVE-2024-3043](https://nvd.nist.gov/vuln/detail/CVE-2024-3043) [1] has been reserved for this vulnerability.

## Description

- Sending a coordinator realignment packet with destination mode set to long address from outside the network causes the devices on the network to change their panID and shortID.

- An attacker may be able to use this vulnerability to cause the victim node to join it’s own network, thus leading to a denial of service.

### Fix/Workaround

- Impacted users should upgrade EmberZNet to one of the versions specified in the table below. The recommended mitigation is to update to the latest GSDK. However, the mitigation for this vulnerability has been backported to the branches summarized in the table below:

- Instructions for downloading/updating the GSDK [2] and for upgrading a project to use a new GSDK version [3] can be found in the Simplicity Studio Users Guide.

| Part | SDK Version | Bug ID | Release Notes |
