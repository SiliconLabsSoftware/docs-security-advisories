# Silicon Labs Security Advisory A-00000593 : Malformed Wi-Fi beacon may cause crash on WF200

Flags: WiFi

CVSS Severity: High

CVSS String: [CVSS:4.0/AV:A/AC:L/AT:N/PR:N/UI:N/VC:N/VI:N/VA:H/SC:N/SI:N/SA:N​](https://www.first.org/cvss/calculator/4.0#CVSS:4.0/AV:A/AC:L/AT:N/PR:N/UI:N/VC:N/VI:N/VA:H/SC:N/SI:N/SA:N​)

## Product Impact
|Product|Impacted Version|Main SDK|Impacted Version|CVE|
|-------|----------------|--------|----------------|----|
|WF200 FW|3.17.0 and earlier|-|-|CVE-2026-107359|
## Description

Due to a vulnerability in Wi-Fi beacon frame handling, a malformed Wi-Fi beacon received by a WF200 may result in a fault and subsequent denial-of-service until a reset is performed.
### Fix/Workaround

Impacted devices should upgrade to a fix version according to the table below. 
|Product|Fix Version|Bug ID|Release Notes|
|--------|------------|-------|---------------|
|WF200|3.18.0 or later|1867|[WF200 Release Notes](https://github.com/SiliconLabs/wfx-firmware/blob/master/CHANGES.md)|
