# Silicon Labs Security Advisory A-00000553 : Security Advisory for Reflected XSS vulnerability in Simplicity Device Manager tool

Flags: Security

CVSS Severity: High

CVSS Base Score: 7.5, High

CVSS String: [CVSS:4.0/AV:N/AC:L/AT:P/PR:N/UI:A/VC:H/VI:H/VA:H/SC:N/SI:N/SA:N](https://www.first.org/cvss/calculator/4.0#CVSS:4.0/AV:N/AC:L/AT:P/PR:N/UI:A/VC:H/VI:H/VA:H/SC:N/SI:N/SA:N)

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Simplicity Device Manager tool | 0.99.35 - alpha and earlier | - | - | [CVE-2025-11004](https://nvd.nist.gov/vuln/detail/CVE-2025-11004) |

### Source Product Impact Details

- Simplicity Device Manager tool delivered as a part of Simplicity Studio 6 is impacted by this vulnerability.

| Product | Impacted Version |
| --- | --- |
| Simplicity Device Manager tool | Version 0.99.35 - alpha and below |

## CVE ID(s)

- [CVE-2025-11004](https://nvd.nist.gov/vuln/detail/CVE-2025-11004) has been reserved for this issue.

## Description

- The Simplicity Device Manager Tool has a Reflected XSS (Cross-site-scripting) vulnerability in several API endpoints.
    - These APIs can affect confidentiality, integrity, and availability of the system that has Simplicity Device Manager tool running in the background.
    - The attacker needs to be on the same network as the victim to successfully execute this attack.

### Fix/Workaround

- To mitigate the risk, upgrade the tool to the mentioned fix version.
    - Simplicity Device Manager tool is delivered as an extension of Simplicity Studio version 6.
    - Install the latest version of Simplicity Device Manager tool using the instructions linked [here](https://github.com/SiliconLabsSoftware/simplicity-device-manager).

| Product | Fix Version |
| --- | --- |
| Simplicity Device Manager | Simplicity Device manager version 0.100.18 |
