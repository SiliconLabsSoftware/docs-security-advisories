## Description

- The vulnerabilities in the silabser.sys Windows driver for the CP210x have been identified. They are summarized below.
    - [CVE-2026-15417](https://nvd.nist.gov/vuln/detail/CVE-2026-15417) – A local unprivileged user can use incorrect driver settings to cause a kernel crash
    - [CVE-2026-15418](https://nvd.nist.gov/vuln/detail/CVE-2026-15418) – A local unprivileged user with a malicious device can use malformed packets to leak up to 145 bytes of uninitialized kernel pool memory
    - [CVE-2026-15419](https://nvd.nist.gov/vuln/detail/CVE-2026-15419) – A local unprivileged user with a malicious device can use malformed packets to corrupt kernel pool memory, resulting in arbitrary code execution with escalated privileges.

### Fix/Workaround

- Details concerning which vulnerabilities impact which versions of silabser.sys can be found in the table below.
- Cross-signing support has been discontinued for Windows 8 drivers, so a fixed version will not be made available for Windows 8.
- Updated drivers can be found [here](https://www.silabs.com/software-and-tools/usb-to-uart-bridge-vcp-drivers?tab=downloads).



| CVE Number | Description | Windows 8 | Windows 10 | Windows 11 |
| --- | --- | --- | --- | --- |
| CVE-2026-15417 | Denial-of-service | Impacted | Not impacted in v11.5.0 | Not impacted in v11.5.0 |
| CVE-2026-15418 | Information Leakage | Impacted | Fixed in v11.6.0 | Not impacted in v11.5.0 |
| CVE-2026-15419 | Memory Corruption results in Arbitrary Code Execution | Impacted | Fixed in v11.6.0 | Fixed in v11.6.0 |
