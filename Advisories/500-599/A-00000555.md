## Description

- Several vulnerabilities are fixed in third-party library, Mbed TLS 3.6.4. Please see the CVEs for details

### Fix/Workaround

- Affected users should upgrade to Simplicity SDK Version 2025.12.0 or later

- Instructions for [downloading/updating the SDK](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-about-the-launcher/toolbar#install) and for [upgrading a project](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) can be found in the Simplicity Studio Users Guide

| Simplicity SDK | 2025.12.0 | 1430901 | [Simplicity SDK 2025.12.0 Release Notes](https://docs.silabs.com/sisdk-release-notes/2025.12.0/sisdk-release-notes-overview/) |
