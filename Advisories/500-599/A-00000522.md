# Silicon Labs Security Advisory A-00000522 : DoS caused due to wrong hash length returned for SHA2/224 algorithm

Flags: Security

CVSS Severity: High

CVSS Base Score: 7.5, High

CVSS Temporal Score: 6.7, Medium

CVSS String: CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H/E:P/RL:O/RC:C

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| WiSeConnect SDK | 3.3.4 and earlier | SiSDK | 2026.6.2 and earlier | [CVE-2024-8361](https://nvd.nist.gov/vuln/detail/CVE-2024-8361) |

### Source Product Impact Details

- SiWx91x devices running WiSeConnect 3.3.4, and earlier, delivered as part of Simplicity SDK 2024.6.2 and earlier

Note: As of June 2024, the Gecko SDK was renamed to the Simplicity SDK and the versioning scheme was changed from Gecko SDK vX.Y.Z to Simplicity SDK YYYY.MM.Patch#.

## CVE ID(s)

- [CVE-2024-8361](https://nvd.nist.gov/vuln/detail/CVE-2024-8361) is reserved for this issue

## Description

- SHA2/224 algorithm in WiSeConnect SDK returns a hash of 256 bits instead of 224 bits

- Incorrect hash length triggers a software assertion, which subsequently causes a Denial of Service (DoS)
    - If a watchdog is implemented, device will restart after watchdog expires
    - If watchdog is not implemented, device can be recovered only after a hard reset

### Fix/Workaround

- To mitigate the issue, upgrade to WiSeConnect SDK version 3.4.0 or later, delivered as part of Simplicity SDK 2024.12.0 or later

- Instructions for [updating the Simplicity SDK](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-about-the-launcher/toolbar#install) and for [upgrading a project to a new Simplicity SDK version](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) can be found in the Simplicity Studio Users Guide

- Please refer to the [WiSeConnect](https://github.com/SiliconLabs/wiseconnect/blob/master/docs/release-notes/index_soc.md) release notes for more information for the fix implemented
