# Silicon Labs Security Advisory A-00000595: Privileged search-path hijacking in CP210x Universal Windows Driver

CVSS Severity: High

## Description

* A privileged executable search-path vulnerability exists in the UpdateParam.bat script included with Silicon Labs CP210x Universal Windows Driver version 11.6.0.
* The script is used to update CP210x registry parameters and is documented to be executed with administrator privileges. However, it invokes the Windows Registry Editor (regedit.exe) without specifying an absolute path to the trusted system executable.
* An attacker with sufficient local filesystem access to place a malicious executable named regedit.exe in the extracted driver package directory may cause the malicious executable to run instead of the legitimate Windows Registry Editor when an administrator executes UpdateParam.bat.
* Successful exploitation may allow attacker-controlled code to execute with elevated administrator privileges, potentially compromising the confidentiality, integrity, and availability of the affected Windows system.
* Exploitation requires the attacker to place a malicious executable in the relevant directory and an administrator to execute the script. The practical exploitability is constrained by filesystem permissions and the requirement for administrator interaction.
* The vulnerability affects the UpdateParam.bat utility included in the Windows driver package. It does not represent a demonstrated vulnerability in the CP210x hardware itself.

### Fix/Workaround

* Silicon Labs has addressed this vulnerability in CP210x Universal Windows Driver version 11.6.0 (2026-OCT-02 release).
* Customers using the affected version should update to version 11.6.0 (2026-OCT-02 release) or later.
* Until the corrected version is installed, customers should avoid executing UpdateParam.bat with administrator privileges from directories containing untrusted files and should ensure that extracted driver packages have not been modified by unauthorized users.
* Instructions for downloading and installing CP210x Universal Windows driver can be found [here](https://www.silabs.com/software-and-tools/usb-to-uart-bridge-vcp-drivers?tab=downloads)
