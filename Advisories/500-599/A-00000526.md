## Description

- DLL hijacking vulnerabilities, caused by an uncontrolled search path, present in Silicon Labs’ installers can lead to privilege escalation and arbitrary code execution. o Exploit is only possible when running the impacted installer.

### Fix/Workaround

- No fix is available for these issues. However, following the guidelines listed below may mitigate risks.
    - Always download Silicon Labs’ installers directly from www.silabs.com.
    - Always download, install, and execute installers from a directory with limited write access.
