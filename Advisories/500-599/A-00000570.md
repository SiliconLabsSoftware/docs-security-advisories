## CVE ID(s)

- [CVE-2025-14055](https://nvd.nist.gov/vuln/detail/CVE-2025-14055) is reserved for this issue.

## Description

- An integer underflow vulnerability exists in the Bluetooth secure NCP host sample application.
- A specially crafted packet may be sent to the host over the NCP interface causing an out-of-bounds memory read of the host memory.

### Fix/Workaround

- Affected users should upgrade Simplicity SDK according to the table below
