## CVE ID(s)

- [CVE-2025-14547](https://nvd.nist.gov/vuln/detail/CVE-2025-14547) is reserved for this issue.

## Description

- An integer underflow vulnerability is present in Silicon Lab’s implementation of PSA Crypto and SE Manager EC-JPAKE APIs during ZKP parsing.
    - Theoretically, the integer underflow can trigger a hard fault, causing a temporary denial of service.

### Fix/Workaround

- Upgrade to the latest version of the SiSDK, listed in the table below, to include the fix that addresses this issue. No fix is available for the GSDK.
- Instructions for updating/downloading can be found [here](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version).
