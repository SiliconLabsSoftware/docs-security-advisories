# Silicon Labs Security Advisory A-00000573 : RS9116 HRNG generates repeated values when power save mode is enabled

Flags: Security, Wi-Fi

CVSS Severity: High

CVSS String: [CVSS:4.0/AV:A/AC:L/AT:P/PR:N/UI:P/VC:H/VI:H/VA:N/SC:N/SI:N/SA:N](https://www.first.org/cvss/calculator/4.0#CVSS:4.0/AV:A/AC:L/AT:P/PR:N/UI:P/VC:H/VI:H/VA:N/SC:N/SI:N/SA:N)

## CVE ID(s)

- [CVE-2026-3290](https://nvd.nist.gov/vuln/detail/CVE-2026-3290) is reserved for this issue

## Description

- RS9116 devices do not support the use of the HRNG (Hardware Random Number Generator) when power save mode is enabled. If it is used, repeated or deterministic values may be observed.
    - This can compromise the confidentiality of sensitive material generated by the HRNG, such as cryptographic keys.

### Fix/Workaround

- A mitigation for the issue is available in RS9116 WiSeConnect SDK 2.14.0 that improves the entropy of numbers provided by the HRNG when power save mode is enabled.

    - To mitigate the issue, impacted users should upgrade to RS9116 SDK 2.14.0 or later. Instructions for updating firmware on RS9116 can be found in AN1290.

- The latest [RS9116 SDK Software Driver Package](https://github.com/SiliconLabs/wiseconnect-wifi-bt-sdk/tree/master) can be downloaded from github. Instructions for [upgrading a project to a new firmware version](https://docs.silabs.com/rs9116-wiseconnect/latest/wifibt-wc-getting-started-with-pc/update-evk-firmware#updating-rs9116-w-firmware) can be found in the RS9116 SDK documentation.
