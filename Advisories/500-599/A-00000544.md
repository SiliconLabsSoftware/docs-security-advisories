## CVE ID(s)

The following CVE has been published for this vulnerability:

- [CVE-2021-36647](https://nvd.nist.gov/vuln/detail/CVE-2021-36647)

## Description

- A vulnerability exists in the third-party library, Mbed TLS, as described below:
- A broken or risky algorithm was used in the Mbed TLS API mbedtls_mpi_exp_mod which could allow an attacker with specific knowledge of timing and memory accesses to gain access to RSA private keys.
- No Silicon Labs stacks implement or use RSA for signatures or encryption.

### Fix/Workaround

- Affected users should upgrade to Gecko SDK 4.0.0, or later

- Instructions for [downloading/updating the SDK](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-about-the-launcher/toolbar#install) and for [upgrading a project](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) can be found in the Simplicity Studio Users Guide
