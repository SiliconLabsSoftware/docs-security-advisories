## Description

- The official [CSA Matter implementation](https://github.com/project-chip/connectedhomeip/tree/master) uses a DRBG for random number generation. Each platform must define how this DRBG is seeded.
- The now deprecated standalone [Silicon Labs Matter Github](https://github.com/SiliconLabs/matter) project, a fork of the CSA Matter repo, served as a starting point for Matter development on several different hardware platforms including the SiWx917.
- Due to a bug in the SiWx917 initialization, the DRBG used by Matter was not initialized correctly for this device. This caused all random numbers generated in the Matter code to use the same stream of numbers. This significantly compromises the confidentiality of any sensitive material generated by the device, including key material.
    - If key material is leaked, this can result in a further loss of the availability,confidentiality, and integrity of the network.
- The impacted Silicon Labs Matter GitHub project is deprecated and has been replaced by the [Matter Extension](https://github.com/SiliconLabs/matter_extension/tree/main), which is distributed with the Simplicity SDK.
- The Silicon Labs Matter Extension as well as the CSA Matter implementation are NOT impacted by this vulnerability.

### Fix/Workaround

- SiWx917 Matter projects should use the Matter Extension distributed with the Simplicity SDK.Instructions for upgrading to the Matter extension can be found in the [SiSDK Matter release notes](https://docs.silabs.com/sisdk-release-notes/latest/sisdk-matter-release-notes/#project-upgrades).
