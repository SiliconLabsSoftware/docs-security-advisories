## CVE ID(s)

- [CVE-2025-10933](https://nvd.nist.gov/vuln/detail/CVE-2025-10933) is reserved for this issue.

## Description

- An integer underflow vulnerability exists in the Z-Wave Protocol Controller’s zwave_command_class_list_unpack API which can lead to out-of-bounds memory reads.

### Fix/Workaround

- Affected users should upgrade to version 1.7.1, or later, of the Z-Wave-protocol-controller according to the instructions found here [https://github.com/SiliconLabsSoftware/z-wave-protocol-controller](https://github.com/SiliconLabsSoftware/z-wave-protocol-controller)

- Download links for the latest Z-Wave Protocol Controller are available here [https://github.com/SiliconLabsSoftware/z-wave-protocol-controller/releases](https://github.com/SiliconLabsSoftware/z-wave-protocol-controller/releases)
