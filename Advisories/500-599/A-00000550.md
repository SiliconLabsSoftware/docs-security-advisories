## Description

- These vulnerabilities are present in a 3rd party library distributed in the SiWx917 WiSeConnect 3 SDK.
    - For additional details, refer to the linked third-party CVEs.
- [CVE-2024-1544](https://nvd.nist.gov/vuln/detail/CVE-2024-1544)

    - In ECDSA, the modular reduction used to generate nonces leaks side channel information, creating curve dependent biases exploitable via lattice attacks. The amount of bias leaked is dependent on the curve used, with SECP160R1 listed as having 15 bits of bias leaked.

        - SiWx917 does not support curve SECP160R1.

        - SiWx917 supports ECDSA P256 for signing. Bias leakage for this curve is minimal according to WolfSSL.

- [CVE-2024-5814](https://nvd.nist.gov/vuln/detail/CVE-2024-5814)

    - A malicious TLS 1.2 server can force a TLS 1.3 client to silently downgrade to TLS 1.2.

        - To exploit this vulnerability, a MiTM attack must have been previously established.

### Fix/Workaround

- No fix is planned for release at the time of this advisory publication.

- Workarounds are available for the following:

    - [CVE-2024-5814](https://nvd.nist.gov/vuln/detail/CVE-2024-5814)

        - Downgrade capability can be disabled on the client to prevent the attack from being exploitable.
