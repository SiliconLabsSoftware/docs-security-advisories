## Description

- A Zigbee coordinator, router, or end device may change its node ID when an unsolicited, encrypted rejoin response is received
- A change in node ID causes Denial of Service (DoS)
- To recover from this DoS attack:
    - If the affected device is an end device, it needs to be re-added to the network.
    - If the affected device is a router, the router must be re-added to the network, subnet nodes will be automatically added once router is added to the network.
    - If the affected device is a coordinator, the entire network needs to be re-established
