
# Silicon Labs Security Advisory A-00000591 : Unvalidated ZWAVE_CMD_NODES_EXIST may cause deletion of end nodes​

Flags: Z-Wave

CVSS Severity: Medium

CVSS String: [CVSS:4.0/AV:N/AC:L/AT:N/PR:L/UI:N/VC:N/VI:L/VA:L/SC:N/SI:N/SA:N](https://www.first.org/cvss/calculator/4.0#CVSS:4.0/AV:N/AC:L/AT:N/PR:L/UI:N/VC:N/VI:L/VA:L/SC:N/SI:N/SA:N)

## Description
 * The Z-Wave “Nodes Exist” command sends a list of nodes and asks if those nodes exist in the network​. This command can also be used to remove nodes if the following conditions are met:​
    * it is sent during an Automatic Controller Update
    * the sender is a SUC ID Server

 * A bug in affected versions of the Z-Wave SDK is not performing these checks. A malicious actor in the network can exploit this vulnerability to remove nodes from the network


### Fix/Workaround

Instructions for [downloading/updating the SDK](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-about-the-launcher/toolbar#install) and for [upgrading a project](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) can be found in the Simplicity Studio Users Guide.

A fix for Z-Wave 700 Series devices is not available at this time.
