## CVE ID(s)

- [CVE-2025-10693](https://nvd.nist.gov/vuln/detail/CVE-2025-10693) was reserved for this issue

## Description

- When SmartStart Inclusion fails during the onboarding of a Z-Wave PIR sensor, the sensor will join the network as a non-secure device.
    - No other devices on the Z-Wave Network are forced to downgrade their security. Only the PIR sensor will be downgraded to a non-secure device. 


### Fix/Workaround

- The fix for this vulnerability is present in the Z-Wave SDK v7.24.2, delivered as part of Simplicity SDK v2025.6.2 and in the Z-Wave SDK v8.0.0, delivered as part of SiSDK v2025.12.0 Refer to the table below for release note details.
    - Instructions for updating/downloading can be found [here](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version).
