## CVE ID(s)

- [CVE-2025-7432](https://nvd.nist.gov/vuln/detail/CVE-2025-7432) is reserved for this issue.

## Description

- DPA countermeasures must be initialized with a random seed value to avoid producing predictable outputs. The seed values used for the DPA countermeasures are not preserved when entering energy mode EM2. This leads to predictable countermeasures upon exiting EM2.
- An attacker with precise timing information may be able to perform a DPA attack in less time than expected.

### Fix/Workaround

- The mitigation for this vulnerability is to reseed the DPA countermeasures upon exiting EM2.

- The fix provided is summarized in the table below.

| Product | Fix Version | Bug ID | Release Notes |
| --- | --- | --- | --- |
| SiSDK | 2025.12.0 / SE firmware 1.2.17 for EFRxG21, or later / SE firmware 2.2.7, or later for all other impacted EFx32xG2xx devices except EFR32xG27 / EFR32xG27 users upgrade to SiSDK 2025.12.0 or later | - | [https://docs.silabs.com/sisdk-release-notes/2025.12.0/sisdk-platform-release-notes/sisdk-plat-security-release-notes](https://docs.silabs.com/sisdk-release-notes/2025.12.0/sisdk-platform-release-notes/sisdk-plat-security-release-notes) |

- Affected users should upgrade their SE firmware using the version included in Simplicity SDK 2025.12.0, or later
- Instructions for [downloading/updating the SDK](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-about-the-launcher/toolbar#install) and for [upgrading a project](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) can be found in the Simplicity Studio Users Guide
- Instructions for updating the SE firmware are found in [https://docs.silabs.com/iot-security/latest/prod-programming-series2-and-series3/11-field-upgrade-the-se-firmware](https://docs.silabs.com/iot-security/latest/prod-programming-series2-and-series3/11-field-upgrade-the-se-firmware)
