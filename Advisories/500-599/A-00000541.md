## Description

- Due to improper input validation, a buffer overflow vulnerability is present in the sl_zigbee_ezsp_get_configuration_value() API. If the buffer overflows, stack corruption is possible. In certain conditions, this could lead to arbitrary code execution.
    - This vulnerability is only present in Zigbee EZSP Host Applications.
- A bad actor must have access to the network key to exploit this vulnerability.
    - This vulnerability does not leak or provide access to the network key, access to this key would need to be obtained before this vulnerability could be exploited.

### Fix/Workaround

- As this vulnerability depends on a bad actor obtaining access to the Zigbee network key, one mitigation strategy is to ensure best practices for key management. The Zigbee network key must always be protected and refreshed regularly.
- The following SDK releases address the vulnerability. Customers are always recommended to upgrade to the latest SDK version available.
    - As additional versions of the SDK are patched with the fix, this table will be updated to reflect new fixes.
- Instructions for upgrading SDK versions can be found in the [Simplicity Studio User’s Guide](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version).
