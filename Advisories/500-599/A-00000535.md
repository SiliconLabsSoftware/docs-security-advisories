# Silicon Labs Security Advisory A-00000535 : Man in the middle attack due to improper renegotiation of handshakes in TLS and SSL

Flags: Security

CVSS Severity: -

CVSS String: -

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| WiSeConnect SDK | 2.11.5 and earlier | SiSDK | 2024.12.2 and earlier | [CVE-2009-3555](https://nvd.nist.gov/vuln/detail/CVE-2009-3555) |
| WiSeConnect SDK | 3.4.2 and earlier | SiSDK | 2024.12.2 and earlier | [CVE-2009-3555](https://nvd.nist.gov/vuln/detail/CVE-2009-3555) |

## CVE ID(s)

- The following CVE is reserved for this issue

| CVE Number | Description |
| --- | --- |
| [CVE-2009-3555](https://nvd.nist.gov/vuln/detail/CVE-2009-3555) | The TLS and SSL 3.0 protocols (possibly earlier) have a vulnerability that allows man-in-the-middle attackers to inject data into secure sessions during renegotiation

## Description

- This notice is intended to notify the users that Silicon Labs’ products include a third-party library, which is affected by this vulnerability. For technical details, please refer to the linked CVE.

### Fix/Workaround

- To mitigate the risk, upgrade to the mentioned fix version, or later for the respective products
    - Instructions for [updating the Simplicity SDK](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-about-the-launcher/toolbar#install) and for [upgrading a project to a new Simplicity SDK version](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) can be found in the Simplicity Studio Users Guide Customers are always recommended to upgrade to the latest SDK version
    - Instructions for [updating the WiSeConnect SDK](https://docs.silabs.com/wiseconnect/latest/wiseconnect-developers-guide-migr-studio-project/upgrading-the-sdk-version-in-the-existing-project) and for [upgrading a project to a new Simplicity SDK version](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) can be found in the Simplicity Studio Users Guide. 
- Customers are always recommended to upgrade to the latest SDK version
