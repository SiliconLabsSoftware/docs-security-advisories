# Silicon Labs Security Advisory A-00000548 : Simplicity Device Manager exposes NTLMv2 hash

Flags: Security

CVSS Severity: High

CVSS Base Score: 7.4, High

CVSS String: [CVSS:4.0/AV:A/AC:L/AT:P/PR:N/UI:P/VC:H/VI:H/VA:N/SC:N/SI:N/SA:N](https://www.first.org/cvss/calculator/4.0#CVSS:4.0/AV:A/AC:L/AT:P/PR:N/UI:P/VC:H/VI:H/VA:N/SC:N/SI:N/SA:N)

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Simplicity Device Manager | 0.100.17 and earlier | - | - | [CVE-2025-10285](https://nvd.nist.gov/vuln/detail/CVE-2025-10285) |

### Source Product Impact Details

- Simplicity Device Manager earlier than version 0.100.18

## CVE ID(s)

- [CVE-2025-10285](https://nvd.nist.gov/vuln/detail/CVE-2025-10285) is reserved for this issue.

## Description

- An unsanitized input to Simplicity Device Manager can lead to an NTLMv2 hash being exposed over the local network.
- This vulnerability is only in scope when Simplicity Device Manager is running.
- The NTLMv2 hash may be used to brute-force the victim’s password.
- A successful attack requires the attacker to be on the network as the victim.

### Fix/Workaround

- Impacted users should upgrade to Simplicity Device Manager 0.100.18, delivered as part of Simplicity Studio 6 1.0.0, or higher

- To determine the version of Simplicity Device Manager currently installed
    1. In Simplicity Studio V6, Click the ‘PACKAGES’ icon
    2. Click the 'Package Manager’ icon
    3. Scroll down to the ‘SOFTWARE’ section and select the ‘Simplicity Device Manager’ item. The version is displayed under the Simplicity Device Manager section.
- The latest version of Simplicity Studio 6 is available at [https://www.silabs.com/software-and-tools/simplicity-studio/simplicity-studio-v6?tab=getting-started](https://www.silabs.com/software-and-tools/simplicity-studio/simplicity-studio-v6?tab=getting-started)
