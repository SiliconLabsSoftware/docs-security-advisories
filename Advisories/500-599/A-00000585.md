## Description

- In 802.15.4 multiprotocol environments, the RAIL library provides a MUX that controls use of the 15.4 lower MAC by different protocols.
- Due to a bug in impacted versions of the RAIL library, it is possible for the Zigbee TX and RAIL MUX to get out-of-sync during times of heavy network traffic. This can result in the device becoming unresponsive while it waits for an ACK that will never be serviced.
- Malicious actors within range of the device can flood the network with traffic to cause the device to become unresponsive.
- If a watchdog has been enabled, the watchdog reset would recover the system. If not, a manual reset is required.
