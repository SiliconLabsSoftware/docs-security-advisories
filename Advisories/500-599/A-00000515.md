## Description

- 4 independent vulnerabilities in the Azure NetX TCP/IP stack, used by the wireless firmware on the RS9116 and SiWx917-based products may lead to remote code execution.

### Fix/Workaround

- Impacted RS9116 customers should upgrade to WiSeConnect 2.10.3, or later, delivered as part of SiSDK 2024.6.2, and update the connectivity firmware on all devices to version 1611.2.10.3.0.2. Instructions for updating can be found in [AN1290: RS9116W Firmware Update Application Note](https://www.silabs.com/documents/login/application-notes/an1290-rs9116w-firmware-update-application-note.pdf).

- Impacted SiWx917 customers should upgrade to WiseConnect 3.3.4, or later, delivered as part of SiSDK 2024.6.2 and update the connectivity firmware on all devices to version 1711.2.12.3.3.0.3, or later. Instructions for updating the connectivity firmware for SoC devices are found [here](https://docs.silabs.com/wiseconnect/3.3.0/wiseconnect-developers-guide-developing-for-silabs-hosts/#update-si-wx91x-connectivity-firmware)[8]. Instructions for updating the connectivity firmware for NCP devices are found [here](https://docs.silabs.com/wiseconnect/3.3.0/wiseconnect-getting-started/getting-started-with-ncp-mode-with-efr32#update-si-wx91x-connectivity-firmware)[9].

- Instructions for [downloading/updating the SiSDK](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-about-the-launcher/toolbar#install) [6] and for [upgrading a project to use a new SiSDK version](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) [7] can be found in the Simplicity Studio Users Guide.
