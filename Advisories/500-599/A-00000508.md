## Description

- [CVE-2024-3051](https://nvd.nist.gov/vuln/detail/CVE-2024-3051)
    - Malformed Device Reset Locally command class packets can be sent to temporarily deny service to an end device.
    - The malformed packets will cause the controller to assume that the end device has left the network, and any frames sent by the end device will not be acknowledged by the controller during this time.

- [CVE-2024-3052](https://nvd.nist.gov/vuln/detail/CVE-2024-3052)
    - Malformed S2 Nonce Get command class packets can be sent to crash the gateway.

    - A hard reset is required to recover the gateway.
