# Silicon Labs Security Advisory A-00000537 : Security advisory for potential buffer overflow in SiWx917 Crypto operations

Flags: Security

CVSS Severity: Medium

CVSS Base Score: 6.0, Medium

CVSS String: CVSS:4.0/AV:N/AC:H/AT:P/PR:L/UI:N/VC:L/VI:H/VA:N/SC:N/SI:N/SA:N

### Source Product Impact Details

- SiWx917 ICs and associated modules running WiseConnect 3.3.4, and earlier delivered as an extension to SiSDK 2024.6.3 and earlier 

Note: As of June 2024, the Gecko SDK was split into two separate products. The actively maintained product, for Series 2 and subsequent products, has been renamed to the Simplicity SDK and the versioning scheme was changed from Gecko SDK vX.Y.Z to Simplicity SDK YYYY.MM.Patch#. The Gecko SDK remains in place for Series 0 and Series 1 products and will continue to use the existing versioning scheme.

## CVE ID(s)

- [CVE-2025-3873](https://nvd.nist.gov/vuln/detail/CVE-2025-3873) has been reserved for this vulnerability.

## Description

- Prior to WiseConnect 3.4.0, an input buffer greater than 1400 bytes passed to any of the following APIs would result in the receiving buffer, allocated on the heap, overflowing.
    - sl_si91x_aes, sl_si91x_gcm, sl_si91x_ccm, sl_si91x_sha

- The observable impact is for the contents of the heap immediately following the receive buffer object to be overwritten.

### Fix/Workaround

- As a workaround, the application should check the size of the inputs passed to the functions mentioned in the technical summary. Any inputs larger than 1400 bytes should be broken into blocks smaller than 1400 bytes.

- To mitigate the issue, upgrade to WiSeConnect SDK version 3.4.0 or later, delivered as part of Simplicity SDK 2024.12.0 or later.

- The fix is for the API to return an error code.

- Instructions for [updating the Simplicity SDK](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-about-the-launcher/toolbar#install) and for [upgrading a project to a new Simplicity SDK version](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) can be found in the Simplicity Studio Users Guide.
