# Silicon Labs Security Advisory A-00000583 : Buffer overflow vulnerability in Bluetooth Mesh extended advertisement handling

Flags: Bluetooth Mesh

CVSS Severity: High

CVSS String: [CVSS:4.0/AV:A/AC:L/AT:P/PR:N/UI:N/VC:H/VI:H/VA:H/SC:L/SI:L/SA:H](https://www.first.org/cvss/calculator/4.0#CVSS:4.0/AV:A/AC:L/AT:P/PR:N/UI:N/VC:H/VI:H/VA:H/SC:L/SI:L/SA:H)

## Description

-	A vulnerability in impacted versions of the SDK can lead to buffer overflows when Bluetooth Mesh provisioners are handling extended advertisements. 
    - These buffer overflows can lead to stack corruption and remote code execution
- For a device to be vulnerable, it must be configured as a provisioner and must accept extended advertisements.

### Fix/Workaround

- Affected users should upgrade Simplicity SDK or GSDK according to the table below
- Instructions for [downloading/updating the SDK](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-about-the-launcher/toolbar#install) and for [upgrading a project](https://docs.silabs.com/simplicity-studio-5-users-guide/latest/ss-5-users-guide-getting-started/project-upgrade-new-gsdk-version) can be found in the Simplicity Studio Users Guide

| Product | Fix Version | Bug ID | Release Notes |
| --- | --- | --- | --- |
| Series 2 | SiSDK 2025.12.0, BT Mesh SDK 10.0.0 | The issue was fixed during a code refactor, so no bug ID was assigned | | 
| Series 0 and Series 1 | GSDK 4.5.1, BT Mesh SDK 6.1.6 | 1621036 | [BT Mesh SDK 6.1.6 Release Notes](https://www.silabs.com/documents/public/release-notes/bt-mesh-software-release-notes-6.1.6.0.pdf) |
