## CVE ID(s)

- [CVE-2025-11571](https://nvd.nist.gov/vuln/detail/CVE-2025-11571) has been reserved for this issue.

## Description

- A command execution vulnerability exists in Simplicity Installer.
- Vulnerable endpoints accept user-controlled input through a URL in JSON format which enables execution of commands.
  - The commands allowed to execute can open an executable. However, the commands cannot pass parameters or arguments.
  - The attacker needs to be on the same network as the victim to successfully execute this attack.

### Fix/Workaround

- To mitigate the risk in Simplicity Studio v6, use the Simplicity Installer tool with mentioned fix version.
  - Install the latest version of Simplicity Studio v6 using the instructions linked [here](https://docs.silabs.com/ssv6ug/latest/install-ssv6/install-simplicity-studio).
- To mitigate the risk in Simplicity Studio v5, install the mentioned version of Simplicity Studio v5 using the instructions linked [here](https://docs.silabs.com/simplicity-studio-5-users-guide/5.11.2/ss-5-users-guide-getting-started/install-ss-5-and-software#install-ssv5).
