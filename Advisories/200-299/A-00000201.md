# Silicon Labs Security Advisory A-00000201 : Security Advisory for Invalid Curve Attack Vulnerability on Older Versions of EFR32xG21 SE Firmware

Flags: Security

CVSS Severity: Medium

CVSS Base Score: 6.5, Medium

CVSS Temporal Score: 5.7, Medium

CVSS String: [CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N/E:U/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N/E:U/RL:O/RC:C)

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| SE Firmware | 1.2.1 and earlier | GSDK | 2.7.2 and earlier | - |

### Source Product Impact Details

- EFR32xG21A products running SE firmware 1.2.1 or earlier in combination with either Gecko SDK 3.1.2 and later or Gecko SDK 2.7.2 or earlier that use ECDH

- EFR32xG21B products are not affected except for a small quantity of devices released under the alpha customer program

- EFR32x21x devices manufactured after October 2020 are not impacted because they are programmed with SE firmware version 1.2.6 or later

- Instructions for determining the SE firmware version currently programmed into an EFR32 device using the command line can be found in section 6.17.1 of [UG162](https://www.silabs.com/documents/public/user-guides/ug162-simplicity-commander-reference-guide.pdf) while instructions for finding the SE firmware version from the user application can be found [here](https://docs.silabs.com/gecko-platform/latest/service/api/group-sl-se-manager-util#ga2611f64267e361b466b11043701ccb01)

## Description

- SE firmware versions earlier than 1.2.2 do not validate ECC input points and can be vulnerable to an invalid curve attack possibly exposing private keys via a key exchange

- Gecko SDK versions 2.7.3 through 3.1.1 includes a compensating control for this vulnerability in the mbed TLS library

- mbed TLS APIs for ECDH in Gecko SDK 3.1.2 return an error code when used with SE firmware earlier than 1.2.2

- The table below indicates which combinations of Gecko SDK and SE firmware are impacted


| SE Firmware | GSDK 2.7.2(or earlier) | GSDK 2.7.3 through 3.1.1 | GSDK 3.1.2 (or later) |
| --- | --- | --- | --- |
| 1.2.1 (or earlier) | Impacted | Not impacted | Impacted |
| 1.2.2 (or later) | Not impacted | Not impacted | Not impacted |

### Fix/Workaround

- Affected systems should upgrade to SE firmware 1.2.2 or later if using GSDK versions 2.7.2 or earlier or 3.1.2 or later. Please see section 5 of [UG266](https://www.silabs.com/documents/public/user-guides/ug266-gecko-bootloader-user-guide.pdf) for upgrade instructions
