# Silicon Labs Security Advisory A-00000259 : Zigbee Denial-of-Service Vulnerability in writeAttributesUndivided Command Handler

Flags: Zigbee

CVSS Severity: Medium

CVSS Base Score: 6.5, Medium

CVSS Temporal Score: 6.0, Medium

CVSS String: [CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:N/I:N/A:H/E:P/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:N/I:N/A:H/E:P/RL:O/RC:C)

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| EmberZNet | 6.8.x and earlier | - | - | - |

### Source Product Impact Details

- Zigbee devices using using Silicon Labs’ application framework together with Ember ZNET versions 6.8.x or earlier

## Description

- An attacker with access to the NWK key can craft a malicious writeAttributesUndivided command with an invalid length field can lead to an infinite code loop in the code responsible for processing the message resulting in a denial of service which will persist until a watchdog reset occurs

### Fix/Workaround

- As an alternative to upgrading the SDK as mentioned above, users can implement their own workaround by copying process-global-message.c found [here](https://github.com/SiliconLabs/PSIRTWA/tree/silabs-steveegerter-A-00000259) and saving it in the SDK under ‘protocol\zigbee\app\framework\util’

- Update to EmberZNET version 6.9.2 or later. EmberZNET versions 6.9.0 and 6.9.1 are not recommended for Zigbee certification reasons 
    1. In SimplicityStudio’s help menu, select the ‘update software’ menu item to open the Installation Manager. 
    2. Click the ‘Manage installed packages’ button.
    3. Select the ‘SDKs’ tab and choose ‘EmberZNET(zigbee)’ from the categories pulldown list then click the ‘Install’ button.
