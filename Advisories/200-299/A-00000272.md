# Silicon Labs Security Advisory A-00000272 : Updated Advisory Zigbee Denial-of-Service Vulnerability in writeAttributesUndivided Command Handler Only Affects EmberZNet 6.7.x

Flags: Zigbee

CVSS Severity: Medium

CVSS Base Score: 5.7, Medium

CVSS Temporal Score: 5.1, Medium

CVSS String: [CVSS:3.1/AV:A/AC:L/PR:L/UI:N/S:U/C:N/I:N/A:H/E:P/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:A/AC:L/PR:L/UI:N/S:U/C:N/I:N/A:H/E:P/RL:O/RC:C)

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| EmberZNet | 6.7.x and earlier | - | - | - |

### Source Product Impact Details

- Zigbee devices using Silicon Labs’ application framework together with EmberZNET version 6.7.x.

## Description

- This is an update to security advisory A-00000259, which is appended at the end this advisory for reference, to correct the following errors in that advisory:

- Only version 6.7.x is impacted. Version 6.8.x is not impacted.

- The CVSS Base Score, Temporal Score, and Vector String have been updated due to correcting the Attack Vector from "Network" to "Adjacent Network". The CVSS Severity of "Medium" is unchanged.
- An attacker with access to the NWK key can craft a malicious writeAttributesUndivided command with an invalid length field can lead to an infinite code loop resulting in a denial of service which will persist until a watchdog reset occurs.

### Fix/Workaround

- As an alternative to upgrading the SDK as mentioned above, users can implement their own workaround by copying process-global-message.c found here and saving it in the SDK under ‘protocol\zigbee\app\framework\util’.

- Update to EmberZNet version 6.8.0 or later as follows: 
    1. In Simplicity Studio’s help menu, select the ‘update software’ menu item to open the Installation Manager. 
    2. Click the ‘Manage installed packages’ button.
    3. Select the ‘SDKs’ tab and choose ‘EmberZNET(zigbee)’ from the categories pulldown list then click the ‘Install’ button.
