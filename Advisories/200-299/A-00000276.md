# Silicon Labs Security Advisory A-00000276 : Temporary Denial-of-Service Vulnerabilities in EmberZNet

Flags: Zigbee

CVSS Severity: Medium

CVSS Base Score: 6.5, Medium

CVSS Temporal Score: 5.9, Medium

CVSS String: [CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H/E:P/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H/E:P/RL:O/RC:C)

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| EmberZNet | 6.9.2 and earlier | GSDK | 3.1.2 and earlier | - |
| EmberZNet | 6.7.9 and earlier | GSDK | 2.7.x and earlier | - |

### Source Product Impact Details

- Zigbee devices using EmberZNet version 6.9.2 and earlier except for 6.7.10+

## Description

- A vulnerable node receives a malicious packet over the Zigbee interface which crashes the stack, resulting in a temporary denial of service while the attacked node resets itself and recovers.

| Bug ID # | Description | Impacted Versions | Impacted Component | Recovery Mechanism | Requires NWK Key? |
| --- | --- | --- | --- | --- | --- |
| #622615 | Memory access violation ASSERT() on receipt of malformed NWK rejoin response | EmberZNet 6.7.0 to 6.9.2 inclusive | Zigbee PRO stack library | ZNet stack will reset the device as soon as the ASSERT occurs, clearing the error | No |
| #622616 | Memory access violation ASSERT() on receipt of malformed NWK rejoin or association request | EmberZNet 6.9.2 and earlier | Zigbee PRO stack library | ZNet stack will reset the device as soon as the ASSERT occurs, clearing the error | No |
| #493695 | Memory access violation ASSERT() in Link Power Delta command or response | EmberZNet 6.0.0 to 6.9.2 inclusive | Zigbee PRO stack library | ZNet stack will reset the device as soon as the ASSERT occurs, clearing the error | Yes |

### Fix/Workaround

- Systems built using GSDK 3.x can upgrade to EmberZNet version 6.10.0 or later, distributed in GSDK 3.2.0 or later

- Systems built using GSDK 2.7.x can upgrade to EmberZNet version 6.7.10 or later, distributed in GSDK 2.7.10 or later. GSDK 2.7.10 is expected to be released in August 2021 
    1. In Simplicity Studio’s help menu, select the ‘update software’ menu item to open the Installation Manager
    2. Click the ‘Manage installed packages’ button 
    3. Select the ‘SDKs’ tab and choose ‘EmberZNET(zigbee)’ from the categories pulldown list then click the ‘Install’ button

Changes from A-00000276 release:

- Bug #622615 and #622616 have been updated to *NOT* require access to the NWK key

- CVSS scores have been updated due to change in the NWK key requirement, specifically the “Privileges Required” field has been changed from “Low” to “None”. There is no change in the overall CVSS severity level of ‘Medium”

- The Technical Summary and the descriptions of each bug have been updated for clarity and correctness

- The Fix/Workaround section has been updated to include the availability of a patch in the 6.7.x branch of EmberZNet. EmberZNet 6.7.10+ has been patched for these issues
