# Silicon Labs Security Advisory A-00000273 : InjectaBLE BLE Security Vulnerability

Flags: Bluetooth

CVSS Severity: Medium

CVSS Base Score: varies

CVSS Temporal Score: varies

CVSS String: varies

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| - | - | - | - | - |

### Source Product Impact Details

- InjectaBLE describes vulnerabilities in the Bluetooth Low Energy protocol when systems are configured to not use encrypted connections, regardless of manufacturer. Bluetooth Low Energy products from Silicon Labs include: EFR32, BLE112, BLE113, BLE121LR, BLED112, BT121, RS9113 and RS9116.
- Products supporting only the Bluetooth Classic protocol are not impacted.

- Bluetooth Low Energy products that are configured to use encrypted connections are not impacted.

## Description

- The report documents four attack vectors for injecting arbitrary packets into an existing, unencrypted connection which are summarized in the table below:

### Fix/Workaround

- The recommended strategy to mitigate all these attacks for all products is to use security level 2 or higher. Silicon Labs recommends using the highest security level supported by the device.

- Please see the following [example](https://docs.silabs.com/bluetooth/2.13/code-examples/stack-features/security/pairing-processes-example) for information on setting up encrypted Bluetooth Low Energy connections.
