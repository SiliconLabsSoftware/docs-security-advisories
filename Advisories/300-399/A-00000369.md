# Silicon Labs Security Advisory A-00000369 : Zigbee Denial of Service Caused by Green Power Toggle Command During Commissioning

Flags: Zigbee

CVSS Severity: Medium

CVSS Base Score: 5.7, Medium

CVSS Temporal Score: 5.5, Medium

CVSS String: [CVSS:3.1/AV:A/AC:L/PR:N/UI:R/S:U/C:N/I:N/A:H/E:H/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:A/AC:L/PR:N/UI:R/S:U/C:N/I:N/A:H/E:H/RL:O/RC:C)

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| EmberZNet | 6.10.3 and earlier | GSDK | 3.2.3 and earlier | - |

### Source Product Impact Details

- EFR32- and EM3xx-based SoCs and modules Running Ember ZNet 6.10.3 and earlier.

## Description

- A Green Power device sending a toggle command during commissioning causes the commissioning device to assert and reset. The reset immediately clears the error.

### Fix/Workaround

- Affected users should upgrade to Ember ZNet 7.0.0 or later, distributed in GSDK 4.0.0 or later as follows:

    1.    In Simplicity Studio’s help menu, select the ‘update software’ menu item to open the Installation Manager
    2.    Click the ‘Manage installed packages’ button
    3. Select the ‘SDKs’ tab
    4. Click the ‘...’ button under ‘Gecko SDK – 32-bit and Wireless MCUs’
    5. Select the ‘Change Version’ item
    6. From the ‘Versions’ pulldown list select 4.0.0 or higher
    7. Click the ‘FINISH’ button
