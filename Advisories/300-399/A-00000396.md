# Silicon Labs Security Advisory A-00000396 : Relay Attacks on Bluetooth LE may allow spoofing of position or range estimation in systems that rely solely on RSSI readings

Flags: Bluetooth

CVSS Severity: Medium

CVSS Base Score: 6.5, Medium

CVSS Temporal Score: 6.1, Medium

CVSS String: [CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:N/I:H/A:N/E:H/RL:W/RC:R](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:N/I:H/A:N/E:H/RL:W/RC:R)

### Source Product Impact Details

- All Bluetooth LE capable SoCs and modules.

## Description

- This is a vulnerability in the Bluetooth LE protocol, all vendors implementations are affected.

- An attacker can alter the received signal strength indication (RSSI) by amplifying Bluetooth LE signals to make a Bluetooth LE device appear to be closer than it is, for example.

- Additional information can be found in the researcher’s paper [here](https://arxiv.org/pdf/2202.06554.pdf).

### Fix/Workaround

- Designs that rely on proximity for access control must not rely entirely on RSSI for proximity detection. It is recommended that some form of user interaction be required to initiate proximity-based operations.
