# Silicon Labs Security Advisory A-00000301 : Bluetooth Vulnerability ‘BrakTooth’ causes Denial-of-Service in iWRAP Modules

Flags: Bluetooth

CVSS Severity: Medium

CVSS Base Score: 4.3, Medium

CVSS Temporal Score: 4.1, Medium

CVSS String: [CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:L/E:P/RL:U/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:L/E:P/RL:U/RC:C)

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| iWRAP stack | - | - | - | [CVE-2021-31609](https://nvd.nist.gov/vuln/detail/CVE-2021-31609), [CVE-2021-31612](https://nvd.nist.gov/vuln/detail/CVE-2021-31612) |


### Source Product Impact Details

- All Silicon Labs Bluetooth Classic modules running the ‘iWrap’ stack including WT11U, WT12, WT32I and WT41U.

- EFR32-based modules and SoCs, RS9113\RS9116-based modules and SoCs, BT121 and BT122 modules are not impacted.

## Description

- A specially crafted ACL LMP packet can cause the module’s firmware to temporarily stop responding to ACL LMP packets resulting in a temporary denial-of-service. The module recovers through an automatic reset.

- Detailed information about this vulnerability is found at [https://asset-group.github.io/disclosures/braktooth/](https://asset-group.github.io/disclosures/braktooth/), [CVE-2021-31609](https://nvd.nist.gov/vuln/detail/CVE-2021-31609) and [CVE-2021-31612](https://nvd.nist.gov/vuln/detail/CVE-2021-31612).

### Fix/Workaround

- For the WTxxx modules, the impacted third-party component is no longer maintained so no patch is available.

- No fix is required for the EFR32, RS9113, RS9116, BT121, or BT122 since they are not impacted.
