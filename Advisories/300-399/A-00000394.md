# Silicon Labs Security Advisory A-00000394 : TRNG Initialization Bug Results in Uninitialized Conditioning Key

Flags: Security

CVSS Severity: Low

CVSS Base Score: 3.1, Low

CVSS Temporal Score: 2.7, Low

CVSS String: [CVSS:3.1/AV:A/AC:H/PR:N/UI:N/S:U/C:L/I:N/A:N/E:U/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:A/AC:H/PR:N/UI:N/S:U/C:L/I:N/A:N/E:U/RL:O/RC:C)

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| - | - | GSDK | 4.0.2 and earlier | - |

### Source Product Impact Details

- Virtual Secure Engine (VSE) SoC’s and modules (ex. EFR32xG22) running GSDK 4.0.2 or earlier may be impacted

## Description

- Random Number Generators (RNGs) may use a conditioning function after the entropy source to reduce bias and/or increase the entropy rate of the raw entropy data.

- A bug in the cryptoacc TRNG initialization code of GSDK 4.0.2 and earlier results in the TRNG being enabled without the conditioning key being initialized. This results in the random data outputs of the TRNG being conditioned with a known key. If there is bias present in the entropy source that is not caught by the internal health checks, an attacker with access to a large sample of random values can detect the entropy source bias.

- An attacker that has detected bias in a TRNG can more easily use brute force attacks to find cryptographic keys and other random data that was generated using that TRNG.

- More information on entropy sources can be found in [NIST SP800-90B](https://csrc.nist.gov/publications/search?keywords-lg=800-90&sortBy-lg=releasedate+DESC&viewMode-lg=brief&ipp-lg=all&status-lg=Final%2CDraft&series-lg=SP&topicsMatch-lg=ANY&controlsMatch-lg=ANY).

### Fix/Workaround

- Affected users should upgrade to GSDK 4.1.0 or later as follows: 
    1. In Simplicity Studio’s Help menu, select the ‘Update Software’ menu item to open the Installation Manager 
    2. Click the ‘Manage installed packages’ button 
    3. Select the ‘SDKs’ tab and find the ‘Gecko SDK – 32-bit and Wireless MCUs’ section 
    4. If there are not currently any Installations, click the ‘Install New’ button. If there is an SDK already installed, click on the ‘...’ button next to its version number 
    5. Click ‘Change Version’
    6. In the ‘Versions:’ dropdown menu, select the desired version
    7. Click ‘FINISH’
