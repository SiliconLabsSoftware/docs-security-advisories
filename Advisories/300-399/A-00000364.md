### Source Product Impact Details

- Changes from A-00000344 release:

    - Overall CVSS severity is updated from high to medium.
    - CVSS scores have been updated to correspond with NIST’s assessments.
    - The Impacted Products section has been updated to clarify the versions of WiSeConnect and n-Link that are impacted for the RS9113- and RS9116-based products.
    - The Fix/Work around section for RS9113 has been updated to indicate that fixes will be available later this year.
    - The Fix/Work around section has been updated to indicate that fixes for RS9116N will be available in early 2022.
    - The technical summary has been corrected to indicate that the WF111 is impacted by [CVE-2020-26140](https://nvd.nist.gov/vuln/detail/CVE-2020-26140), [CVE-2020-26143](https://nvd.nist.gov/vuln/detail/CVE-2020-26143), [CVE-2020-26144](https://nvd.nist.gov/vuln/detail/CVE-2020-26144) and [CVE-2020-26145](https://nvd.nist.gov/vuln/detail/CVE-2020-26145) in AP mode as well as STA mode.

- WF2xx -based modules and SoCs running FW 3.1.1 or earlier are impacted. 
- RS9113-based modules and SoCs running WiSeConnect 1.7.12 or earlier are impacted. 
- RS9113-based modules and SoCs running n-Link 1.6.5 or earlier are impacted. 
- RS9116W-based modules and SoCs running 2.4.0 or earlier are impacted. 
- RS9116N-based modules and SoCs running n-Link 2.3.2.0003 or earlier are impacted. 
- WGM110 modules running 1.1.1 and earlier are impacted. 
- WF111 modules with Linux drivers 5.2.2-r4 and earlier are impacted. 
- WF121 modules running 1.4.1 and earlier are impacted. 
- WGM160P modules running GeckoOS 4.2.7 or earlier are impacted.

### Fix/Workaround

- For RS9113 SoCs and Modules patches will be available later this year.

- For RS9113/RS9116 SoCs and modules update to version 2.4.1.16 or later [here](https://github.com/SiliconLabs/wiseconnect-wifi-bt-sdk). Note that [CVE-2020-24588](https://nvd.nist.gov/vuln/detail/CVE-2020-24588) will not be fixed in these products.

- For RS9116N SoCs and modules, fixes will be available for n-Link early in 2022.

- For WF2XX-based SoCs and Modules update to version 3.12.3 or later available at [https://github.com/SiliconLabs/wfx-firmware](https://github.com/SiliconLabs/wfx-firmware).

- WGM110 customers should update to Wizard Gecko SDK 1.2.0 or later. The latest version of the Wizard Gecko SDK is available [here](https://www.silabs.com/documents/public/software/SiliconLabs-Wizard-Gecko-SDK.exe). Note that the fix for [CVE-2020-26141](https://nvd.nist.gov/vuln/detail/CVE-2020-26141) has not been addressed yet.

- WF121 customers should update to SDK 1.5.0 or later. The latest version on the SDK is available on the [WF121 product page](https://www.silabs.com/wireless/wi-fi/bluegiga-legacy-modules/device.wf121) . Note that the fix for [CVE-2020-26141](https://nvd.nist.gov/vuln/detail/CVE-2020-26141) has not been addressed yet.

- WF111 customers should update to Linux driver 5.2.3-r1 or later. The latest version of this driver is on the [WF111 product page](https://www.silabs.com/wireless/wi-fi/bluegiga-legacy-modules/device.wf111).

- Fixes for GeckoOS, which runs on WGM160P, are not available currently. An updated advisory will be published when the fixes are available.
