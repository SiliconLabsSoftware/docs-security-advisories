# Silicon Labs Security Advisory A-00000335 : Arbitrary Code Execution in Underscore impacts Gateway Management UI

Flags: Security

CVSS Severity: Medium

CVSS Base Score: N/A

CVSS Temporal Score: N/A

CVSS String: N/A

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Gateway Management UI GitHub project | - | - | - | [CVE-2021-23358](https://nvd.nist.gov/vuln/detail/CVE-2021-23358) |

### Source Product Impact Details

- The Gateway Management UI GitHub project found at [https://github.com/SiliconLabs/gateway-management-ui](https://github.com/SiliconLabs/gateway-management-ui).

- The Gateway Management UI project is deprecated and no longer supported by Silicon Labs.

## Description

- [CVE-2021-23358](https://nvd.nist.gov/vuln/detail/CVE-2021-23358) has been reserved for this issue.

- Additional information about this vulnerability is available at [CWE-94](https://cwe.mitre.org/data/definitions/94.html).

- The Underscore package version in the Gateway Management UI GitHub project is vulnerable to arbitrary code injection via the ‘template’ function, particularly when the ‘variable’ option is taken from ‘_.templateSettings’, as it is not sanitized.

### Fix/Workaround

- This issue can be fixed by updating the Underscore library version to 1.13.0-2, 1.12.1 or higher.

- The latest Underscore version can be found at [https://underscorejs.org/](https://underscorejs.org/).

- To update, modify the required version in ‘nodeserver/package.json’, then call ‘npm update’ in the ‘nodeserver’ directory.
