# Silicon Labs Security Advisory A-00000381 : Wi-SUN SDK 1.2.0 vulnerability causes predictable random number generation

Flags: Wi-SUN

CVSS Severity: High

CVSS Base Score: 8.1, High

CVSS Temporal Score: 7.7, High

CVSS String: [CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:N/E:H/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:N/E:H/RL:O/RC:C)

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| Wi-SUN SDK | 1.2.0 | GSDK | 4.0.0 | - |

### Source Product Impact Details

- EFR32 SoC’s and modules running Wi-SUN SDK 1.2.0 distributed with GSDK 4.0.0 may be impacted.

## Description

- A modification made to Wi-SUN SDK 1.2.0 caused the hardware TRNG to always return 0, resulting in a predictable seed value and following bit sequence.

- This could cause random values in the Wi-SUN stack such as source port or TCP sequence number to be predictable.

### Fix/Workaround

- Affected users should upgrade to Wi-SUN SDK 1.2.1 or later, distributed in GSDK 4.0.1 or later as follows: 
    1. In Simplicity Studio’s Help menu, select the ‘Update Software’ menu item to open the Installation Manager 
    2. Click the ‘Manage installed packages’ button
    3.   Select the ‘SDKs’ tab and in the ‘Gecko SDK – 32-bit and Wireless MCUs’ section click the ‘Install New’ button
