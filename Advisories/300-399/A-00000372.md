# Silicon Labs Security Advisory A-00000372 : Log4j Vulnerabilities in Silicon Labs products

Flags: Zigbee

CVSS Severity: Critical

CVSS Base Score: varies

CVSS Temporal Score: varies

CVSS String: varies

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| - | - | - | - | [CVE-2021-4104](https://nvd.nist.gov/vuln/detail/CVE-2021-4104), [CVE-2021-44228](https://nvd.nist.gov/vuln/detail/CVE-2021-44228), [CVE-2021-45046](https://nvd.nist.gov/vuln/detail/CVE-2021-45046), [CVE-2021-44832](https://nvd.nist.gov/vuln/detail/CVE-2021-44832), [CVE-2021-45105](https://nvd.nist.gov/vuln/detail/CVE-2021-45105) |

### Source Product Impact Details

- Thunderboard Sense Zigbee Demo is impacted since it uses Log4j 2.7.

- Simplicity Studio (all versions) is not impacted.

- None of Silicon Labs’ wireless MCUs or associated modules are impacted because they do not run Java.

## Description

- Log4j is a ubiquitous logging component, written in Java, containing several vulnerabilities which are summarized below.

- None of Silicon Labs’ wireless SoCs or modules support Java, so they are not impacted.

- Simplicity Studio uses Log4j 1.2.15 but is not impacted by [CVE-2021-4104](https://nvd.nist.gov/vuln/detail/CVE-2021-4104) since the impacted component, JMSAppender, is disabled by default. For an attacker to enable JMSAppender they would need to modify the Log4j configuration file.

- The Thunderboard Sense Zigbee demo uses Log4j 2.7. The vulnerabilities that impact this application are summarized in the following table:

| Type of Vulnerability | CVE | CVSS |
| --- | --- | --- |
| Remote code execution | [CVE-2021-44228](https://nvd.nist.gov/vuln/detail/CVE-2021-44228) | 9.5, Critical |
| Remote code execution | [CVE-2021-45046](https://nvd.nist.gov/vuln/detail/CVE-2021-45046) | 8.6, High |
| Remote code execution | [CVE-2021-44832](https://nvd.nist.gov/vuln/detail/CVE-2021-44832) | 6.3, Medium |
| Denial of service | [CVE-2021-45105](https://nvd.nist.gov/vuln/detail/CVE-2021-45105) | 5.4, Medium |

- Additional information about these vulnerabilities is available from CERT/CC at [VU#930724](https://kb.cert.org/vuls/id/930724).

### Fix/Workaround

- Users of the Thunderboard Sense Zigbee Demo should uninstall it. Please see the following [knowledgebase article](https://community.silabs.com/s/article/log4j-Analysis-of-Simplicity-Studio-4-and-Simplicity-Studio-5?language=en_US) for specific instructions.

- No fix is required for Simplicity Studio 4 or 5.
