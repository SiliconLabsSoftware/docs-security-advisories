# Silicon Labs Security Advisory A-00000374 : Malformed Packet Causes Assert in EmberZNet Resulting in a Denial-of-Service

Flags: Zigbee

CVSS Severity: Medium

CVSS Base Score: 6.5, Medium

CVSS Temporal Score: 6.2, Medium

CVSS String: [CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H/E:H/RL:O/RC:C](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H/E:H/RL:O/RC:C)

## Product Impact

| Product | Impacted Version | Main SDK | Impacted Version | CVE |
| --- | --- | --- | --- | --- |
| EmberZNet | 7.0.1 and earlier | GSDK | 4.0.1 and earlier | [CVE-2022-24937](https://nvd.nist.gov/vuln/detail/CVE-2022-24937), [CVE-2022-24938](https://nvd.nist.gov/vuln/detail/CVE-2022-24938) |

### Source Product Impact Details

- All SoCs and Modules running EmberZNet, versions according to the table below.

## Description

- A malformed Zigbee packet causes a buffer overflow assert leading to a reset which immediately clears the error.

- Another malformed Zigbee packet causes a stack overflow which results in a CPU usage fault assert. The assert resets the device and immediately clears the error.

| CVE | Description | NWK Key Required? | Bug ID | Versions Impacted |
| --- | --- | --- | --- | --- |
| [CVE-2022-24937](https://nvd.nist.gov/vuln/detail/CVE-2022-24937) | Buffer overflow leads to assert | No | 702666 | 7.0.0 and earlier |
| [CVE-2022-24938](https://nvd.nist.gov/vuln/detail/CVE-2022-24938) | Stack overflow leads to assert | No | 811489 | 7.0.1 and earlier |

### Fix/Workaround

- Customers impacted by bug id 702666 should upgrade to EmberZNet 7.0.1 or later, which is delivered as part of Gecko SDK 4.0.1 or later, instructions below.

- Customers impacted by bug id 811489 should upgrade to EmberZNet 7.0.2 or later, which is delivered as part of Gecko SDK 4.0.2 or later, instructions below. 
    1. In Simplicity Studio’s help menu, click the Update Software meu item to open the Installation Manager dialog.
    2. In the Installation Manager dialog, click the Manage installed packages button.
    3. Select the SDKs tab, then click the Install New button under in the section titled ‘Gecko SDK – 32-bit and
Wireless MCUs’.
